> **本单元核心目标**
>
> 学习更多元音字母组合，重点理解：
>
> 1. 同一个字母组合可能表示不同的元音。
> 2. 不同字母组合可能表示相同的元音。
> 3. 元音发音可能受到相邻辅音、单词结构及英语口音的影响。
> 4. 自然拼读规律需要与具体词汇和阅读经验结合。

# Part 1. 学习目标

完成本单元后，孩子应逐步能够：

- [ ] 掌握 `oo` 表示 /ʊ/ 的常见情况。
- [ ] 掌握 `oo` 表示 /u/ 的常见情况。
- [ ] 区分 /ʊ/ 与 /u/。
- [ ] 认识单词中 `u` 表示 /ʊ/ 的常见情况。
- [ ] 掌握 `ew`、`ui`、`ue` 的常见发音 /u/。
- [ ] 掌握 `au`、`aw`、`augh` 的常见发音 /ɔ/。
- [ ] 掌握 `ea` 表示 /ɛ/ 的常见情况。
- [ ] 认识 `a` 在某些单词中表示 /ɔ/ 的情况。
- [ ] 能根据字母组合尝试拼读陌生单词。
- [ ] 能区分相似元音并正确拼写常见单词。
- [ ] 能在句子、短文和写作中应用本单元知识。

**与 Unit 8 的主要区别：**

Unit 8 主要学习：

- ai、ay → /eɪ/
- ee、ea、ey → /i/
- oa、ow、oe → /oʊ/
- ie、igh → /aɪ/

Unit 9 则进一步学习：

- oo → /ʊ/ 或 /u/
- ew、ui、ue → /u/
- au、aw、augh → /ɔ/
- ea → /ɛ/

孩子开始接触更多**同形异音的拼写模式**。

# Part 2. 中国家长需要理解的基础概念

## 2.1 为什么同一个字母组合会有不同发音？

例如：

**book**

`oo → /ʊ/`

**moon**

`oo → /u/`

虽然两个单词都包含 oo，但元音并不相同。

| 单词 | 元音发音 | 中文 |
|---|---|---|
| book | /ʊ/ | 书 |
| look | /ʊ/ | 看 |
| good | /ʊ/ | 好的 |
| moon | /u/ | 月亮 |
| food | /u/ | 食物 |
| school | /u/ | 学校 |

这说明英语的拼写与发音不是完全一一对应的。

### 与汉语拼音比较

在标准汉语拼音中，同一韵母的发音相对稳定。

例如拼音 `ai` 在不同普通话音节中通常表示相同的韵母。

但英语的 `oo` 可以表示不同元音。

因此，家长不能告诉孩子：

“两个 o 放在一起就一定读某一个音。”

更准确的说法是：

**oo 有几种常见读音，我们先学习最常见的两种，再通过阅读逐步掌握。**

---

## 2.2 /ʊ/ 和 /u/ 有什么区别？

这是本单元最重要的发音对比之一。

| 特征 | /ʊ/ | /u/ |
|---|---|---|
| 常见教学名称 | Short oo | Long oo |
| 舌位 | 较高、较放松 | 较高、通常更靠后 |
| 嘴唇 | 略微收圆 | 通常收圆更明显 |
| 示例 | book, look, good | moon, food, blue |

### 最小对立词（Minimal Pairs）

最小对立词指两个单词只有一个音素不同。

例如：

| /ʊ/ | /u/ |
|---|---|
| full | fool |
| pull | pool |
| look | Luke（人名） |
| foot | — |

其中：

- full → /fʊl/
- fool → /ful/

两个词的元音不同。

### 与汉语拼音比较

英语 /u/ 与普通话拼音 u 有一定相似性。

但英语 /ʊ/ 是一个不同的元音，不能直接用拼音 u 代替。

尤其注意：

**book 不能按照 moon 的元音来读。**

另外，英语中的“长元音”和“短元音”是自然拼读教学名称，不应简单理解为发音时间长短的区别。

---

## 2.3 不同字母组合为什么能表示相同声音？

例如：

- moon
- blue
- fruit
- grew

这些单词中的元音都可以表示 /u/。

| 拼写 | 示例 |
|---|---|
| oo | moon, food |
| ue | blue, true |
| ui | fruit, suit |
| ew | grew, flew |
| u_e | flute, rule |

这意味着孩子听到 /u/ 时，可能有多种拼写选择。

### Decoding 与 Encoding

**Decoding：**

看到 blue，知道 ue 表示 /u/。

**Encoding：**

听到 blue，需要知道正确拼写是 `blue`，而不是其他可能表示相同发音的组合。

所以：

**自然拼读可以帮助孩子读出陌生单词，但准确拼写还需要积累词汇的具体书写形式。**

---

## 2.4 什么是 /ɔ/？

/ɔ/ 是英语中的一个后元音。

例如在保留 /ɔ/ 与 /ɑ/ 区别的美式英语口音中：

- saw → /sɔ/
- law → /lɔ/
- caught → /kɔt/

### 与汉语拼音比较

英语 /ɔ/ 不能直接等同于拼音 o。

它通常需要更明显地张开嘴巴，并保持一定的圆唇特征。

### 美国口音差异：Cot–Caught Merger

这是中国家长特别值得了解的现象。

在美国一些地区，以下两个元音可能合并：

- /ɑ/
- /ɔ/

例如：

- cot
- caught

部分美国人会把它们读得相同或非常接近。

因此，如果孩子从不同老师、同学或音频中听到不同的发音，不一定意味着有人读错了。

**家庭练习应优先采用学校老师使用的英语口音，不必强迫孩子区分当地口音中已经合并的元音。**

# Part 4. 逐课知识点与家庭练习

## Lesson 89 — oo、u /ʊ/

### 1. 学习目标

掌握 `oo` 和部分 `u` 表示 /ʊ/ 的情况。

### 2. 示例单词

**oo → /ʊ/**

| 单词 | 中文 |
|---|---|
| book | 书 |
| look | 看 |
| cook | 烹饪 |
| hook | 钩子 |
| foot | 脚 |
| good | 好的 |
| wood | 木头 |
| stood | 站立（过去式） |
| brook | 小溪 |
| shook | 摇晃（过去式） |

**u → /ʊ/**

| 单词 | 中文 |
|---|---|
| put | 放 |
| pull | 拉 |
| push | 推 |
| full | 满的 |
| bull | 公牛 |
| bush | 灌木丛 |

### 3. 发音解释

例如：

`book → /b/ /ʊ/ /k/`

`look → /l/ /ʊ/ /k/`

`put → /p/ /ʊ/ /t/`

其中：

- book 中 oo 共同表示一个元音。
- put 中 u 表示 /ʊ/，不是常见短 u /ʌ/。

### 4. 与之前短元音 u 比较

| 单词 | 元音 |
|---|---|
| cut | /ʌ/ |
| cup | /ʌ/ |
| sun | /ʌ/ |
| put | /ʊ/ |
| pull | /ʊ/ |
| push | /ʊ/ |

**注意：cut 和 put 的元音不同。**

不能因为两个单词都包含 u，就认为它们使用相同的元音。

### 5. 与汉语拼音比较

英语 /ʊ/ 不能直接用汉语拼音 u 代替。

家长可以通过 full 与 fool 的对比帮助孩子听辨。

### 6. 家庭练习

**音素分割**

- book → /b/ /ʊ/ /k/
- look → /l/ /ʊ/ /k/
- good → /g/ /ʊ/ /d/
- put → /p/ /ʊ/ /t/

**Word Chains**

Chain A：

`book → cook → hook → look → took`

每一步替换首辅音。

Chain B：

`put → pull`

这一步同时改变末辅音结构，可作为单词比较，不作为严格单步链。

推荐严格单步练习：

`book → cook → hook → look`

**听写**

- book
- look
- good
- foot
- put
- pull

### 7. 家长常见错误

- 将 book 的 oo 读成 moon 中的 /u/。
- 将 put 的 u 读成 cut 中的 /ʌ/。
- 认为所有 oo 都表示同一个元音。
- 将 oo 当成两个独立音节。

## Lesson 90 — oo /u/

### 1. 学习目标

掌握 `oo` 表示 /u/ 的常见情况，并与 Lesson 89 的 /ʊ/ 区分。

### 2. 示例单词

| 单词 | 中文 |
|---|---|
| moon | 月亮 |
| food | 食物 |
| soon | 很快 |
| room | 房间 |
| pool | 游泳池 |
| cool | 凉爽的 |
| school | 学校 |
| spoon | 勺子 |
| tooth | 牙齿 |
| boot | 靴子 |
| zoo | 动物园 |
| noon | 中午 |

### 3. 发音解释

例如：

`moon → /m/ /u/ /n/`

`food → /f/ /u/ /d/`

`school → /s/ /k/ /u/ /l/`

注意 school 中的 sch 不是一个独立字素；这里的 s、ch（表示 /k/）和 oo 分别参与拼读，包含后续或特殊拼写知识。

### 4. oo 两种发音的对比

| /ʊ/ | /u/ |
|---|---|
| book | moon |
| look | food |
| good | pool |
| foot | boot |
| wood | spoon |

这些是发音分类示例，并不都是最小对立词。

### 5. 与汉语拼音比较

英语 /u/ 与拼音 u 有一定相似性，但应以标准英语示范为准。

尤其注意，英语 /ʊ/ 和 /u/ 是不同元音，不能简单理解为同一个声音的快慢区别。

### 6. 家庭练习

**Word Chains**

`moon → noon → soon`

`pool → cool → fool → tool`

每一步替换首音。

**听音分类**

家长读：

book, moon, look, food, good, pool, foot, boot

孩子将单词分成 /ʊ/ 和 /u/ 两组。

**听写**

- moon
- food
- room
- pool
- spoon
- boot

### 7. 家长常见错误

- 将所有 oo 都读成 /u/。
- 认为 /u/ 只是 /ʊ/ 的延长。
- 将 oo 拆成两个元音音节。

## Lesson 91 — ew、ui、ue /u/

### 1. 学习目标

学习表示 /u/ 的其他常见拼写：

- ew
- ui
- ue

同时认识这些组合在某些词中可能表示 /ju/。

### 2. 示例单词

**ew**

| 单词 | 中文 |
|---|---|
| grew | 生长（过去式） |
| flew | 飞（过去式） |
| blew | 吹（过去式） |
| chew | 咀嚼 |
| threw | 扔（过去式） |
| screw | 螺丝 |

**ui**

| 单词 | 中文 |
|---|---|
| fruit | 水果 |
| suit | 西装 |
| juice | 果汁 |
| cruise | 巡航 |
| bruise | 瘀伤 |

**ue**

| 单词 | 中文 |
|---|---|
| blue | 蓝色 |
| true | 真实的 |
| glue | 胶水 |
| clue | 线索 |
| due | 到期的；应得的 |
| Sue | 苏（人名） |

### 3. 发音解释

例如：

`blue → /b/ /l/ /u/`

`fruit → /f/ /r/ /u/ /t/`

`grew → /g/ /r/ /u/`

注意：

- ue 在 blue 中表示 /u/。
- ui 在 fruit 中表示 /u/。
- ew 在 grew 中表示 /u/。

### 4. 为什么有些 ew、ue 读 /ju/？

英语中的 /ju/ 包含：

- /j/：类似 yes 开头的辅音。
- /u/：元音。

例如：

- few → /fju/
- new → /nu/ 或 /nju/，取决于口音
- due → /du/ 或 /dju/，取决于口音

在常见美式英语中，new、due 往往不包含明显的 /j/。

因此，不同单词和口音可能有所差异。

### 5. 与汉语拼音比较

英语 /u/ 与拼音 u 有一定相似性。

但 /ju/ 并不是简单的拼音 u。

家长可以借助英语单词 yes 中的 /j/ 理解 /ju/ 的开头滑音。

### 6. 家庭练习

**分类**

将以下单词分成 ew、ui、ue 三组：

grew, fruit, blue, flew, suit, glue, chew, juice, true

**音素分割**

- blue → /b/ /l/ /u/
- fruit → /f/ /r/ /u/ /t/
- grew → /g/ /r/ /u/

**Word Chains**

`blue → clue → glue`

`grew → drew → threw`

第二条每一步主要替换首辅音结构，可能涉及不止一个音素的变化，适合拼写模式比较。

**听写**

- blue
- true
- glue
- fruit
- suit
- grew

### 7. 家长常见错误

- 将 ew、ui、ue 分别读成两个元音。
- 认为所有 ew、ue 都必须发 /u/。
- 忽略 /u/ 与 /ju/ 的差异。
- 将 fruit 误读成两个音节。

## Lesson 93 — au、aw、augh /ɔ/

### 1. 学习目标

学习表示 /ɔ/ 的常见拼写模式：

- au
- aw
- augh

### 2. 示例单词

**au**

| 单词 | 中文 |
|---|---|
| August | 八月 |
| author | 作者 |
| autumn | 秋天 |
| cause | 原因；导致 |
| pause | 暂停 |
| sauce | 酱汁 |
| launch | 发射；启动 |
| fault | 错误；过失 |

**aw**

| 单词 | 中文 |
|---|---|
| saw | 看见（过去式）；锯子 |
| law | 法律 |
| paw | 动物的爪子 |
| draw | 画 |
| straw | 吸管；稻草 |
| crawl | 爬行 |
| yawn | 打哈欠 |
| lawn | 草坪 |

**augh**

| 单词 | 中文 |
|---|---|
| caught | 抓住（过去式） |
| taught | 教（过去式） |
| daughter | 女儿 |
| naughty | 淘气的 |

### 3. 发音解释

例如：

`saw → /s/ /ɔ/`

`caught → /k/ /ɔ/ /t/`

`author → /ˈɔ.θɚ/`

注意：

- aw 在 saw 中表示一个元音。
- augh 在 caught 中通常表示 /ɔ/。
- au 在 author 中通常表示 /ɔ/。

### 4. 与汉语拼音比较

英语 /ɔ/ 不能直接用汉语拼音 o 代替。

另外，英语 au 不等于汉语拼音 ao，也不是字母 a 和 u 分别发音。

### 5. 为什么 caught 和 cot 在美国可能同音？

因为部分美式英语口音存在 Cot–Caught Merger。

在这些口音中，/ɔ/ 与 /ɑ/ 可能合并。

因此：

- cot
- caught

可能读得相同。

家长应以学校老师使用的口音为主要参考。

### 6. 家庭练习

**分类**

将以下单词分成 au、aw、augh：

saw, caught, author, law, taught, August, draw, sauce, daughter

**Word Chains**

`law → saw → paw → raw`

`caught → taught`

后者主要改变首辅音。

**音素分割**

- saw → /s/ /ɔ/
- paw → /p/ /ɔ/
- caught → /k/ /ɔ/ /t/

**听写**

- saw
- law
- draw
- caught
- taught
- August

### 7. 家长常见错误

- 将 au 按汉语拼音 ao 发音。
- 将 aw 拆成两个元音。
- 将 caught 中的 gh 单独发音。
- 认为所有 augh 都表示 /ɔ/。

例如 laugh 中的 augh 不遵循 caught 的发音模式。

## Lesson 94 — ea /ɛ/、a /ɔ/

### 1. 学习目标

学习：

- ea 表示 /ɛ/ 的常见情况。
- a 在某些单词中表示 /ɔ/ 的情况。

### 2. ea /ɛ/ 示例单词

| 单词 | 中文 |
|---|---|
| bread | 面包 |
| head | 头 |
| dead | 死的 |
| read（过去式） | 读了 |
| ready | 准备好的 |
| heavy | 重的 |
| weather | 天气 |
| feather | 羽毛 |
| spread | 展开；传播 |
| instead | 代替 |

### 3. 为什么 ea 不总是发 /i/？

在 Unit 8 中，孩子学习：

`ea → /i/`

例如：

- team
- sea
- leaf

但本课学习：

`ea → /ɛ/`

例如：

- bread
- head
- ready

### 4. 对比

| ea /i/ | ea /ɛ/ |
|---|---|
| team | bread |
| sea | head |
| leaf | dead |
| clean | ready |
| dream | heavy |

### 5. a /ɔ/ 示例单词

在部分美式英语口音中，a 位于某些辅音之后时，可能表示 /ɔ/。

例如：

- ball
- call
- tall
- wall
- small
- fall
- salt
- talk
- walk

其中：

- ball、call、tall 等属于之前学习过的 -all 模式。
- salt、talk、walk 涉及其他特殊拼写规律。

需要注意，a 在这些词中的具体音值存在地区口音差异，不能把 /ɔ/ 视为所有美国人的统一发音。

### 6. 与汉语拼音比较

英语字母 a 不一定表示 /æ/ 或 /eɪ/。

例如：

- cat → /æ/
- cake → /eɪ/
- ball → /ɔ/（部分美式口音）
- car → /ɑr/

因此，英语字母 a 的发音比汉语拼音 a 更复杂。

### 7. 家庭练习

**ea 分类**

将以下单词分成 /i/ 和 /ɛ/：

team, bread, sea, head, leaf, ready, clean, heavy

**Word Chains**

`head → dead → lead`

注意 lead 有不同读音：作为金属“铅”时读 /lɛd/，作为动词“引导”时读 /lid/。

更适合初学者的练习：

`head → dead → bread → dread`

其中 dead → bread 增加 /b/ 和 /r/，不是严格单步变化。

建议分组练习：

- head → dead
- bread → dread

**听写**

- bread
- head
- ready
- heavy
- ball
- call

### 8. 家长常见错误

- 将所有 ea 都读成 /i/。
- 认为所有 a 都只能表示短 a 或长 a。
- 忽略英语口音差异。
- 认为 read 在所有语境中发音相同。

Luke had a good book.

The moon was bright.

Luke looked at the moon.

He saw a picture of a blue boat.

# Part 7. 中国家长常见问题

### Q1：为什么 book 和 moon 中的 oo 发音不同？

因为 oo 可以表示不同元音。

- book：/ʊ/
- moon：/u/

需要通过常见词汇和拼写模式逐步掌握。

### Q2：为什么 put 和 cut 的 u 发音不同？

因为 put 中的 u 通常表示 /ʊ/，cut 中的 u 通常表示 /ʌ/。

英语同一个字母可能表示不同元音。

### Q3：为什么 blue、fruit、moon 的元音相同？

因为 ue、ui、oo 都可以表示 /u/。

这说明同一个音素可能有多种拼写。

### Q4：为什么 ew 有时表示 /u/，有时表示 /ju/？

这与英语的辅音环境、历史发音和口音差异有关。

例如：

- grew：/u/
- few：/ju/

### Q5：为什么 caught 和 cot 在一些美国人口中听起来一样？

因为部分美式英语口音存在 Cot–Caught Merger，使 /ɔ/ 与 /ɑ/ 合并。

### Q6：为什么 ea 在 team 和 bread 中发音不同？

因为 ea 有多种常见发音。

- team：/i/
- bread：/ɛ/

以后还会遇到 great 中的 /eɪ/。

### Q7：孩子是不是必须记住所有例外？

不需要一次全部记住。

建议：

1. 先掌握最常见的拼写模式。
2. 通过阅读积累常见单词。
3. 对容易混淆的单词进行分类练习。
4. 在听写中逐步建立准确的拼写记忆。

# Part 10. 本单元总结

## 三个最重要的学习成果

**1. 理解相同字母组合可以表示不同元音。**

例如：

- book：oo → /ʊ/
- moon：oo → /u/
- team：ea → /i/
- bread：ea → /ɛ/

**2. 理解不同拼写可以表示相同元音。**

例如：

- moon、blue、fruit：/u/
- saw、caught、August：/ɔ/（在保留该音位区别的口音中）

**3. 能结合拼写模式与词汇记忆阅读陌生单词。**

例如：

- good
- school
- fruit
- caught
- bread

## 下一单元预告

**Unit 10 — Diphthongs（双元音）**

下一单元将重点学习：

- oi、oy → /ɔɪ/
- ou、ow → /aʊ/
- 其他相关的双元音拼写模式

例如：

- coin、boy
- cloud、cow
- house、brown

下一单元的核心概念是：

**双元音是一个音节中的元音音质变化，而不是两个独立的音节。**

例如：

- coin：一个音节。
- boy：一个音节。
- cow：一个音节。

这也是中国家长可以借助汉语拼音复韵母来理解，但需要特别注意英语实际发音差异的知识点。
