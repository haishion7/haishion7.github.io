# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Vowel Team？

Vowel Team 是自然拼读教学中常用的术语，通常指两个或多个字母组合表示一个元音音素的拼写模式。

例如：

`rain`

- r → /r/
- ai → /eɪ/
- n → /n/

所以 rain 有4个字母，但只有3个音素。

再例如：

`boat`

- b → /b/
- oa → /oʊ/
- t → /t/

boat 也有4个字母、3个音素。

### 与 Digraph 的联系

在之前的单元中，孩子已经学过：

- sh → /ʃ/
- ch → /tʃ/
- th → /θ/ 或 /ð/

这些属于辅音字母组合。

现在学习：

- ai → /eɪ/
- ee → /i/
- oa → /oʊ/

这些属于元音字母组合。

两者的共同点是：多个字母共同表示一个声音。

### 需要特别注意

Vowel Team 并不总是恰好由两个元音字母组成。

例如：

`igh → /aɪ/`

虽然 igh 有三个字母，其中只有 i 是传统元音字母，但在自然拼读教学中仍作为一个长元音拼写模式学习。

---

## 2.2 Long Vowel（长元音）到底是什么意思？

在英语自然拼读中，Long Vowel 通常指与元音字母名称相同的发音。

| 字母 | 字母名称对应的发音 | 示例 |
|---|---|---|
| A | /eɪ/ | rain, play |
| E | /i/ | see, team |
| I | /aɪ/ | pie, light |
| O | /oʊ/ | boat, snow |
| U | /ju/ | cute（前面已学） |

**注意：Long Vowel 不等于把短元音的发音时间拉长。**

例如：

- /æ/ 和 /eɪ/ 是不同的元音。
- /ɪ/ 和 /aɪ/ 是不同的元音。
- /ɑ/ 和 /oʊ/ 是不同的元音。

其中 /eɪ/、/aɪ/、/oʊ/ 在常见美式英语中是双元音，发音过程中舌位会发生变化。

---

## 2.3 与汉语拼音的比较

汉语拼音也存在由多个字母组成的韵母，例如：

- ai
- ei
- ao
- ou

这些韵母可以帮助中国家长理解“多个字母共同表示一个语音单位”的概念。

但英语的 Vowel Teams 与汉语拼音韵母并不能直接一一对应。

例如：

| 英语 | 发音 | 汉语拼音参考 | 注意 |
|---|---|---|---|
| rain | /reɪn/ | ei | 只是近似参考 |
| pie | /paɪ/ | ai | 实际音质不同 |
| boat | /boʊt/ | ou | 需要模仿英语双元音 |
| see | /si/ | i | 英语元音不完全等于拼音 i |

### 为什么不能直接套用拼音？

因为英语的字母组合不一定按照字母本身的名称发音。

例如：

`ai → /eɪ/`

不是先读字母 A 的名称，再读字母 I 的名称。

`oa → /oʊ/`

也不是把字母 O 和 A 分别读出来。

**家长应帮助孩子把整个字母组合作为一个拼写单位来识别。**

---

## 2.4 Vowel Teams 与 VCe 有什么区别？

在 Unit 4 中，我们已经学习过 VCe（Silent e）。

例如：

`cap → cape`

现在又学习：

`rain`

两者都可以表示长元音，但拼写结构不同。

| 模式 | 示例 | 长元音 |
|---|---|---|
| VCe | cake | /eɪ/ |
| Vowel Team | rain | /eɪ/ |
| Vowel Team | play | /eɪ/ |
| VCe | kite | /aɪ/ |
| Vowel Team | pie | /aɪ/ |
| Vowel Team | light | /aɪ/ |
| VCe | hope | /oʊ/ |
| Vowel Team | boat | /oʊ/ |
| Vowel Team | snow | /oʊ/ |

### 核心区别

**VCe：**

元音字母与词尾 e 之间通常隔着一个辅音字母。

例如：

`c-a-k-e`

**Vowel Team：**

多个字母组成一个元音拼写单位。

例如：

`r-ai-n`

### 家长需要理解

孩子以后听到 /eɪ/ 时，可能需要在以下拼写之间选择：

- a_e
- ai
- ay

因此：

**Decoding（看到字母读出声音）通常比 Encoding（听到声音确定正确拼写）更容易。**

---

## 2.5 为什么同一个声音有不同拼写？

例如长元音 /eɪ/：

- cake
- rain
- play

三个单词使用不同拼写。

英语的拼写受到历史发音变化、词源以及正字法规则等因素影响。

因此，英语自然拼读需要学习：

1. 字母或字母组合的常见发音。
2. 不同拼写模式的常见位置。
3. 常见例外。
4. 通过大量阅读逐步建立准确的词汇拼写记忆。

### 与中文识字比较

学习中文时，孩子会利用偏旁和形声字规律帮助识字。

例如：

- 清
- 情
- 晴
- 请

这些字有共同的声旁，但声调或读音可能不同。

英语的 ai、ay、a_e 也可以通过归类学习。

两者的语言机制不同，但教学上都强调：

**利用规律提高识别效率，而不是孤立记忆每一个词。**

# Part 4. 逐课知识点与家庭练习

## Lesson 84 — ai、ay /eɪ/

### 1. 学习目标

学习 `ai` 和 `ay` 通常表示长元音 /eɪ/。

**核心规律：**

- `ai` 常出现在单词或音节内部。
- `ay` 常出现在单词或音节末尾。

这是一种常见拼写倾向，并非绝对规则。

### 2. 示例单词

**ai**

| 单词 | 中文 |
|---|---|
| rain | 雨 |
| train | 火车 |
| mail | 邮件 |
| tail | 尾巴 |
| sail | 航行；帆 |
| wait | 等待 |
| paint | 油漆；绘画 |
| snail | 蜗牛 |
| brain | 大脑 |
| chain | 链条 |

**ay**

| 单词 | 中文 |
|---|---|
| day | 天 |
| play | 玩 |
| say | 说 |
| may | 可能；五月 |
| stay | 停留 |
| tray | 托盘 |
| gray | 灰色 |
| clay | 黏土 |
| spray | 喷洒 |
| away | 离开；远离 |

### 3. 发音解释

`rain → /r/ /eɪ/ /n/`

`play → /p/ /l/ /eɪ/`

注意：

- ai 表示一个元音音素 /eɪ/。
- ay 也表示一个元音音素 /eɪ/。
- 不能把 a 和 i、a 和 y 分别发音。

### 4. ai 与 ay 的拼写位置

| 拼写 | 常见位置 | 示例 |
|---|---|---|
| ai | 词中 | rain, mail, train |
| ay | 词尾 | day, play, stay |

比较：

- rain，不写作 rayn。
- play，不写作 plai。
- train，不写作 trayn。

这些对比用于说明标准拼写，不能把错误形式当作练习词。

### 5. 与汉语拼音比较

英语 /eɪ/ 与汉语拼音 ei 有一定听觉相似性。

但英语 rain 中的 ai 并不读成拼音 ai。

这是中国家长非常容易误解的地方：

**英语字母组合 ai 发 /eɪ/，而汉语拼音 ai 表示另一个双元音。**

### 6. 家庭练习

**音素分割**

- rain → /r/ /eɪ/ /n/
- train → /t/ /r/ /eɪ/ /n/
- play → /p/ /l/ /eɪ/
- snail → /s/ /n/ /eɪ/ /l/

**Word Chains**

Chain A：

`rain → pain → paid → maid → mail → tail`

每一步改变一个音素。

Chain B：

`day → say → may → pay → play`

最后一步增加 /l/。

**听写**

- rain
- train
- mail
- day
- play
- stay

### 7. 家长常见错误

- 将 ai 按汉语拼音 ai 发音。
- 将 ai 或 ay 拆成两个独立元音。
- 认为 ai、ay 可以在任何位置随意替换。
- 认为所有 ai 都发 /eɪ/。

例如 said 中的 ai 发 /ɛ/，属于需要特别学习的常见词。

## Lesson 85 — ee、ea、ey /i/

### 1. 学习目标

学习 `ee`、`ea`、`ey` 通常表示长元音 /i/。

### 2. 示例单词

**ee**

| 单词 | 中文 |
|---|---|
| see | 看见 |
| tree | 树 |
| green | 绿色 |
| feet | 脚（复数） |
| seed | 种子 |
| sleep | 睡觉 |
| sheep | 绵羊 |
| three | 三 |
| street | 街道 |
| week | 星期 |

**ea**

| 单词 | 中文 |
|---|---|
| eat | 吃 |
| sea | 海 |
| tea | 茶 |
| team | 团队 |
| leaf | 叶子 |
| clean | 干净的 |
| dream | 梦 |
| beach | 海滩 |
| read | 阅读（现在时） |
| speak | 说话 |

**ey**

| 单词 | 中文 |
|---|---|
| key | 钥匙 |
| monkey | 猴子 |
| donkey | 驴 |
| honey | 蜂蜜 |
| valley | 山谷 |
| turkey | 火鸡 |
| money | 钱 |

### 3. 发音解释

例如：

`see → /s/ /i/`

`team → /t/ /i/ /m/`

`key → /k/ /i/`

这些单词中的 ee、ea、ey 通常表示同一个元音 /i/。

### 4. 为什么 ee、ea、ey 可以表示同一个音？

英语同一个音素可能具有不同的历史拼写形式。

在本阶段，家长不需要给孩子讲复杂词源。

重点是帮助孩子理解：

- 看到 ee，通常尝试读 /i/。
- 看到 ea，在本课的常见词中通常读 /i/。
- 看到 ey，在部分词尾中通常读 /i/。

### 5. 与汉语拼音比较

英语 /i/ 与汉语拼音 i 在部分环境中有相似性。

但不能认为英语 ee 就是两个拼音 i 连续发音。

例如：

`see → /si/`

只有一个元音音素，而不是两个音节。

### 6. ea 的重要例外

ea 并不总是发 /i/。

例如：

| 单词 | ea 的发音 |
|---|---|
| team | /i/ |
| sea | /i/ |
| bread | /ɛ/ |
| head | /ɛ/ |
| great | /eɪ/ |
| break | /eɪ/ |

另外：

- read（现在时）通常读 /rid/。
- read（过去式）通常读 /rɛd/。

两者拼写完全相同，但发音不同。

这是以后理解英语同形异音词（Heteronyms）的好例子。

### 7. 家庭练习

**音素分割**

- see → /s/ /i/
- sheep → /ʃ/ /i/ /p/
- team → /t/ /i/ /m/
- key → /k/ /i/

**Word Chains**

Chain A：

`see → seed → feed → feet → meet`

其中 feed → feet 改变末辅音。

Chain B：

`team → beam → bean → mean → meat`

每一步改变一个音素。

**分类**

将以下单词分成 ee、ea、ey 三组：

see, tree, team, leaf, key, monkey, green, clean, honey

**听写**

- see
- tree
- green
- team
- leaf
- key

### 8. 家长常见错误

- 将 ee 读成两个元音。
- 认为 ea 永远发 /i/。
- 认为 ey 在所有单词中都发 /i/。
- 把英语 /i/ 简单等同于汉语拼音 i。

例如 they 中的 ey 发 /eɪ/，不符合本课学习的常见 ey /i/ 模式。

## Lesson 86 — oa、ow、oe /oʊ/

### 1. 学习目标

学习 `oa`、`ow`、`oe` 通常表示长元音 /oʊ/。

### 2. 示例单词

**oa**

| 单词 | 中文 |
|---|---|
| boat | 船 |
| coat | 外套 |
| goat | 山羊 |
| road | 道路 |
| soap | 肥皂 |
| loaf | 一条面包 |
| float | 漂浮 |
| toast | 吐司 |
| coach | 教练 |
| throat | 喉咙 |

**ow**

| 单词 | 中文 |
|---|---|
| snow | 雪 |
| grow | 生长 |
| show | 展示 |
| slow | 慢的 |
| blow | 吹 |
| flow | 流动 |
| throw | 扔 |
| window | 窗户 |
| yellow | 黄色 |
| pillow | 枕头 |

**oe**

| 单词 | 中文 |
|---|---|
| toe | 脚趾 |
| hoe | 锄头 |
| doe | 母鹿 |
| foe | 敌人 |
| goes | 去（第三人称单数） |

### 3. 发音解释

`boat → /b/ /oʊ/ /t/`

`snow → /s/ /n/ /oʊ/`

`toe → /t/ /oʊ/`

其中：

- oa 表示 /oʊ/。
- ow 在这些词中表示 /oʊ/。
- oe 在这些词中表示 /oʊ/。

### 4. 拼写位置规律

| 拼写 | 常见位置 | 示例 |
|---|---|---|
| oa | 词中 | boat, road, soap |
| ow | 词尾或音节末尾 | snow, grow, yellow |
| oe | 词尾 | toe, hoe, doe |

这可以帮助孩子在听写时选择更可能的拼写。

但英语并非完全规则，仍需通过阅读积累具体词汇。

### 5. 与汉语拼音比较

英语 /oʊ/ 与汉语拼音 ou 有一定听觉相似性。

但英语单词 boat 中的 oa 不等于拼音 oa。

不能按照两个字母分别发音。

### 6. ow 的两种常见发音

这一点特别重要。

英语 `ow` 可以表示：

**/oʊ/**

- snow
- grow
- slow

也可以表示：

**/aʊ/**

- cow
- now
- how
- brown

本课主要学习 ow /oʊ/，而 /aʊ/ 将在后续 Diphthongs 单元系统学习。

### 7. 家庭练习

**音素分割**

- boat → /b/ /oʊ/ /t/
- goat → /g/ /oʊ/ /t/
- snow → /s/ /n/ /oʊ/
- toe → /t/ /oʊ/

**Word Chains**

Chain A：

`boat → coat → goat → moat`

Chain B：

`snow → slow → glow → grow`

其中 slow → glow 改变首辅音；glow → grow 改变第二个辅音。

**分类**

将以下单词分成 oa、ow、oe：

boat, snow, toe, road, grow, coat, hoe, soap, show

**听写**

- boat
- coat
- road
- snow
- grow
- toe

### 8. 家长常见错误

- 将 oa 拆成两个元音。
- 将 snow 中的 ow 读成 /aʊ/。
- 认为 ow 只有一种发音。
- 将 oe 的 e 单独读出来。

## Lesson 87 — ie、igh /aɪ/

### 1. 学习目标

学习 `ie`、`igh` 通常表示长元音 /aɪ/。

### 2. 示例单词

**ie**

| 单词 | 中文 |
|---|---|
| pie | 馅饼 |
| tie | 领带；系 |
| lie | 躺；说谎 |
| die | 死亡 |
| cried | 哭了 |
| tried | 尝试了 |
| fried | 油炸的 |

**igh**

| 单词 | 中文 |
|---|---|
| high | 高的 |
| light | 光；轻的 |
| night | 夜晚 |
| right | 正确的；右边 |
| bright | 明亮的 |
| fight | 打架 |
| sight | 视力；景象 |
| might | 可能 |
| tight | 紧的 |
| flight | 飞行 |

### 3. 发音解释

例如：

`pie → /p/ /aɪ/`

`light → /l/ /aɪ/ /t/`

`night → /n/ /aɪ/ /t/`

注意：

**igh 虽然有三个字母，但通常共同表示一个元音音素 /aɪ/。**

例如 light：

- 字母数量：5个。
- 音素数量：3个。
- 音节数量：1个。

### 4. 为什么 igh 中的 gh 不发音？

英语拼写保留了历史发音变化的痕迹。

在现代英语中，light、night、high 等单词中的 gh 通常不发音。

但 gh 在其他单词中可能表示不同声音，例如 laugh 中的 gh 表示 /f/。

本课先学习 `igh → /aɪ/` 的常见模式。

### 5. 与汉语拼音比较

英语 /aɪ/ 与汉语拼音 ai 有一定听觉相似性。

但 `igh` 并不是 i、g、h 三个字母分别发音。

例如：

`night → /naɪt/`

不能把 gh 读出来。

### 6. ie 的其他发音

ie 并不总是表示 /aɪ/。

例如：

- pie：/paɪ/
- field：/fild/
- chief：/tʃif/

在 field、chief 中，ie 表示 /i/。

因此，孩子需要逐步学习不同的拼写模式，而不是认为 ie 永远读 /aɪ/。

### 7. 家庭练习

**音素分割**

- pie → /p/ /aɪ/
- high → /h/ /aɪ/
- light → /l/ /aɪ/ /t/
- bright → /b/ /r/ /aɪ/ /t/

**Word Chains**

Chain A：

`light → night → right → fight → sight`

每一步替换首音。

Chain B：

`pie → tie → lie → die`

每一步替换首音。

**分类**

将以下单词分成 ie、igh：

pie, light, tie, night, high, lie, bright, fight

**听写**

- pie
- tie
- high
- light
- night
- bright

### 8. 家长常见错误

- 将 igh 拆成三个独立声音。
- 将 gh 读成 /g/ 或 /h/。
- 认为所有 ie 都发 /aɪ/。
- 把 light 读成两个音节。

# Part 5. UFLI 教学方法与家庭练习

## 5.1 八个教学环节

| UFLI 环节 | 学习目标 | 家庭练习 |
|---|---|---|
| Phonemic Awareness | 听辨长元音 | rain、see、boat、light |
| Visual Drill | 看字母组合说发音 | ai、ay、ee、ea、oa、ow、igh |
| Auditory Drill | 听声音选择拼写 | 听 /eɪ/，讨论 ai、ay、a_e |
| Blending Drill | 将音素合成为单词 | /r/ /eɪ/ /n/ → rain |
| New Concept | 学习新的 Vowel Team | 解释 ai 与 ay |
| Word Work | 拼读、拼写和变换 | rain → pain → paid |
| Irregular Words | 学习高频特殊词 | said、they 等 |
| Connected Text | 阅读句子与短文 | 阅读包含 Vowel Teams 的故事 |

### 特别提醒：Auditory Drill

如果家长只发出 /eɪ/，孩子无法仅凭声音确定应该写：

- a_e
- ai
- ay

因此，在听写单词时，应结合完整单词和拼写位置进行判断。

例如：

- rain：ai 通常出现在词中。
- play：ay 通常出现在词尾。
- cake：a_e 属于 VCe 模式。

# Part 7. 中国家长常见问题

### Q1：为什么 rain 中的 ai 不读成汉语拼音 ai？

因为英语字母组合 ai 通常表示 /eɪ/，与汉语拼音 ai 的发音不同。

英语自然拼读需要按照英语的拼写与发音规律学习，不能直接套用汉语拼音。

### Q2：为什么 rain 和 play 的元音发音一样，拼写却不同？

因为 ai 和 ay 都可以表示 /eɪ/。

它们具有常见的位置规律：

- ai 经常位于词中。
- ay 经常位于词尾。

但仍需要结合具体单词学习。

### Q3：为什么 see 有两个 e，却只有一个元音音素？

因为 ee 共同表示 /i/。

see 的音素是 /s/ 和 /i/，一共两个。

### Q4：为什么 ea 有时读 /i/，有时读 /ɛ/？

因为 ea 存在多种常见发音。

例如：

- team：/i/
- bread：/ɛ/
- great：/eɪ/

本课先学习最常见的 /i/ 模式，后续再扩展其他情况。

### Q5：为什么 snow 和 cow 中的 ow 发音不同？

因为 ow 可以表示不同的双元音：

- snow：/oʊ/
- cow：/aʊ/

这需要通过不同的拼写模式和具体词汇逐步掌握。

### Q6：为什么 light 中的 gh 不发音？

因为英语保留了一些历史拼写。

在 light、night、high 等词中，igh 通常共同表示 /aɪ/。

但 gh 在其他单词中可能表示不同声音，例如 laugh 中的 /f/。

### Q7：孩子需要记住所有 Vowel Teams 的名称吗？

不需要机械背诵术语。

孩子最重要的是：

1. 看到字母组合能尝试读出声音。
2. 听到单词能分析音素。
3. 能根据常见拼写规律写出单词。
4. 能在阅读中理解单词的意义。

**Unit 9 — Other Vowel Teams（其他元音字母组合，Lessons 89–94）**

主要学习：

| Lesson | 知识点 | 示例 |
|---|---|---|

| 93 | au、aw、augh /ɔ/ | August, saw, caught |

下一单元的核心概念是：

**相同的元音字母组合可能表示不同的声音，而不同字母组合也可能表示相同的元音。**

例如：

- book 与 moon 都包含 oo，但发音不同。
- blue、fruit、moon 使用不同拼写，却可以包含相同的 /u/ 元音。

这将进一步帮助孩子理解英语自然拼读的规律与例外。
