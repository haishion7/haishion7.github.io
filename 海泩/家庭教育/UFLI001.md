# Part 1. 先理解英语自然拼读

## 1.1 什么是 Phonics（自然拼读）？

自然拼读是一种帮助孩子建立**书面字母与口语声音之间联系**的教学方法。

例如，孩子看到：

`cat`

可以尝试识别三个字母表示的声音：

- c → /k/
- a → /æ/
- t → /t/

然后把三个声音连续合起来：

`/k/ + /æ/ + /t/ → cat`

这叫作 **Decoding（解码、拼读）**。

反过来，听到 cat，孩子也可以将它拆成三个音，再写出对应的字母：

`cat → /k/ /æ/ /t/ → c-a-t`

这叫作 **Encoding（编码、拼写）**。

### 与汉语拼音的对比

中国孩子学习拼音时，也会经历类似过程。

例如：

`m + a → ma`

再结合声调读出 `mā`、`má`、`mǎ`、`mà`。

两者的共同点是：**通过学习符号与声音之间的对应关系，掌握阅读和拼写的方法，而不是单纯记忆整个词的外形。**

但有几个重要区别：

| 对比 | 汉语拼音 | 英语自然拼读 |
|---|---|---|
| 基本用途 | 用拉丁字母标注普通话发音 | 学习英语书写与发音的对应规律 |
| 基本单位 | 声母、韵母、声调等 | 音素、字母及字母组合 |
| 对应规律 | 拼写与读音相对稳定 | 一个字母可能有多种发音 |
| 声调 | 有词汇声调 | 没有汉语式词汇声调，但有重音和语调 |
| 示例 | m + a → mā | c + a + t → cat |

**家长需要特别理解：英语自然拼读不是一套能够百分之百准确预测所有单词读音的规则。**

例如：

- cat：a → /æ/
- cake：a → /eɪ/
- car：a → /ɑr/（常见美式发音）
- about：a → /ə/

因此，孩子先学习最常见的规律，之后再逐步学习其他拼写模式及特殊情况。

## 1.2 Letter、Phoneme、Grapheme 有什么区别？

这是家长理解自然拼读最重要的三个概念。

| 英文 | 中文 | 解释 |
|---|---|---|
| Letter | 字母 | 书写符号，如 a、b、c |
| Phoneme | 音素 | 能区别词义的最小语音单位 |
| Grapheme | 字素 | 表示音素的一个字母或字母组合 |

### 例子一：cat

- 字母数量：3（c、a、t）
- 字素数量：3（c、a、t）
- 音素数量：3（/k/、/æ/、/t/）

### 例子二：ship

- 字母数量：4（s、h、i、p）
- 字素数量：3（sh、i、p）
- 音素数量：3（/ʃ/、/ɪ/、/p/）

其中 `sh` 是两个字母组成的一个字素，通常表示一个音素 /ʃ/。

### 例子三：box

- 字母数量：3（b、o、x）
- 字素数量：3（b、o、x）
- 音素数量：4（/b/、/ɑ/、/k/、/s/，按常见美式读音）

因为 x 在 box 中通常表示 /k/ 和 /s/ 两个音素。

### 与汉语拼音的对比

可以借助拼音中的 `sh` 来理解：

- 拼音 `sh`：两个字母表示一个声母。
- 英语 `sh`：两个字母通常表示一个音素 /ʃ/。

**注意：两种语言的 sh 并不完全同音。**

英语 /ʃ/ 通常比普通话拼音 `sh` 的舌位更靠前，也没有普通话 `sh` 那样明显的卷舌特征。

## 1.3 Phonemic Awareness（音素意识）

音素意识指的是：**不看文字，仅凭听觉，就能识别、合成、分割或改变单词中的声音。**

这与认识字母不同。

例如，家长说：

`map`

孩子不看任何文字，也能够听出：

`/m/ /æ/ /p/`

说明孩子具有相应的音素分割能力。

### 四种常见练习

| 能力 | 英文 | 示例 |
|---|---|---|
| 首音识别 | Initial Sound Identification | map 的第一个音是 /m/ |
| 末音识别 | Final Sound Identification | map 的最后一个音是 /p/ |
| 音素合成 | Phoneme Blending | /m/ /æ/ /p/ → map |
| 音素分割 | Phoneme Segmenting | map → /m/ /æ/ /p/ |

更进一步，还可以练习音素替换：

家长说：

“Say map. Change /m/ to /t/.”

孩子回答：

“tap.”

### 与汉语拼音的对比

学习拼音时，我们常常练习：

`b + a → ba`

英语音素意识则可以完全不展示字母：

家长只发出 /b/、/æ/、/t/ 三个声音，让孩子合成为 bat。

这有点像在孩子看到拼音之前，先让他通过听觉识别声音的组成。

但英语音素意识更强调单词内部的每个音素，而不是只划分声母和韵母。

**家长提醒：** 不要在辅音后面额外加上“呃”之类的元音。例如 /m/ 应尽量发成连续的鼻音，而不是“么”。否则孩子合音时容易多出一个声音。

# Part 2. 字母与基础发音

## 2.1 英语26个字母

英语共有26个字母，其中：

- 常见元音字母：a、e、i、o、u
- 其他21个通常归为辅音字母
- y 有时表示辅音，有时表示元音

**元音字母（Vowel Letters）与元音音素（Vowel Sounds）不是同一个概念。**

英语只有5个传统元音字母，但元音音素远不止5个。

例如字母 a 可以表示 /æ/、/eɪ/ 等不同元音。

| b | /b/ | bat, big | 双唇闭合后释放，声带振动 |

| h | /h/ | hat, hop | 轻轻呼气 |

| z | /z/ | zip, zoo | 与 /s/ 相似，但声带振动 |

### 中国家长容易混淆的发音

**1. /b/ 与 /p/**

汉语拼音 b 和 p 主要通过送气区别，而英语 /b/ 和 /p/ 主要通过清浊等发音特征区别。

不要直接认为英语 b 就等于拼音 b。

**2. /v/ 与 /w/**

- /v/：上齿轻触下唇，例如 van。
- /w/：双唇收圆，例如 wet。

**3. /s/ 与 /z/**

两者发音位置相似，但 /z/ 需要声带振动。

可以让孩子轻触喉咙，比较：

- sip
- zip

**4. /r/ 与 /l/**

- /l/：舌尖通常接触上齿龈。
- /ɹ/：美式英语中舌头不应像 /l/ 一样抵住上齿龈。

例如：

- red / led
- right / light
- road / load

- am

1. 展示 m，问：“What sound?”
2. 展示 a，问：“What sound?”

5. 让孩子连续合音，读出 mat。

#### VC 与 CVC 是什么意思？

C = Consonant（辅音）

V = Vowel（元音）

**VC：**

- am
- at
- in
- it

**CVC：**

- mat
- sat
- pin
- sit
- fan

CVC 描述的是音素结构，不是简单地数单词有几个字母。

例如 ship 虽然有4个字母，但按音素结构仍然是 CVC，因为 sh 表示一个辅音音素。

#### Word Chain 练习

`mat → sat → sit → sip → tip → tin`

每次只替换一个音素。

例如：

- mat → sat：/m/ 变为 /s/
- sat → sit：/æ/ 变为 /ɪ/
- sit → sip：/t/ 变为 /p/

注意：这是一条综合复习链，家长应等相关字母全部学过后再使用。

#### Nasalized A 是什么？

在部分美式英语口音中，短元音 /æ/ 出现在 /m/、/n/ 等鼻音前时，发音可能受到影响。

例如：

- am
- an
- man
- ham

家长不需要让孩子死记复杂的语音学规则。更重要的是通过标准录音和口语示范，让孩子熟悉这些词的自然发音。

### 为什么短元音很重要？

英语的许多基础单词只因为中间元音不同，就变成另一个单词。

例如：

| 单词 | 元音 | 意思 |
|---|---|---|
| bat | /æ/ | 蝙蝠；球棒 |
| bet | /ɛ/ | 打赌 |
| bit | /ɪ/ | 一小块 |
| bot | /ɑ/ | 机器人程序（非典型基础教学词） |
| but | /ʌ/ | 但是 |

家长可以让孩子练习：

`pat → pet → pit → pot → put`

但最后的 put 使用 /ʊ/，不符合本阶段所学的短 u /ʌ/ 规律，因此可作为以后学习英语发音例外的例子，而不是初学时要求孩子自行拼读的词。

### 与汉语拼音的区别

汉语拼音的 a、o、e、i、u 并不能直接对应英语的短元音。

尤其注意：

- 英语 /æ/ 不等于拼音 a。
- 英语 /ɪ/ 不等于拼音 i。
- 英语 /ʌ/ 不等于拼音 u。

例如 sit 的元音 /ɪ/ 是一个较短、较放松的元音，不应直接读成汉语拼音 `si` 中的韵母。

### 为什么词尾 s 有不同的发音？

英语中，词尾 -s 经常用于复数或动词变化。

例如：

- cat → cats
- dog → dogs
- cup → cups
- pen → pens

但它并不总是读 /s/。

| 前一个音素 | 词尾 -s | 示例 |
|---|---|---|
| 清辅音 /t/、/p/、/k/ 等 | /s/ | cats, cups, books |
| 浊辅音 /g/、/n/、/b/ 等 | /z/ | dogs, pens, bags |

以后还会学习第三种常见情况：

- buses
- boxes
- dishes

这些词的复数结尾通常形成额外的 /ɪz/ 音节。

**家长可以这样理解：** 这有点类似汉语中连续发音会受到相邻声音影响的现象，但英语词尾 -s 的具体发音规律与汉语变调不同。

### 家庭活动：听声音分类

准备两列：

**/s/**

- cats
- maps
- cups
- books

**/z/**

- dogs
- pens
- bags
- beds

家长随机读词，孩子将单词分到正确的类别。

不必先讲复杂语法，重点是听出区别。

### 特别知识点一：x 通常表示两个音素

例如：

`box → /b/ /ɑ/ /k/ /s/`

虽然 box 只有3个字母，却包含4个音素。

家长可以问：

“How many letters?”

孩子回答：“Three.”

“How many sounds?”

孩子回答：“Four.”

其他例子：

- fox
- six
- mix

### 特别知识点二：qu 通常表示 /kw/

例如：

- quit
- quiz
- quick
- quack

以 quit 为例：

`/k/ /w/ /ɪ/ /t/`

一共4个音素。

注意：这并不意味着 q 在所有英语单词中都必须与 u 同时出现，只是基础自然拼读中常见的规律。

### 特别知识点三：y 可以表示辅音或元音

本阶段先学习 y 表示辅音 /j/：

- yes
- yellow
- yet
- yam

后续还会学习：

- my：y 表示 /aɪ/
- happy：y 表示 /i/
- gym：y 表示 /ɪ/

这也是英语自然拼读需要逐步扩展规则的原因。

# Part 4. UFLI 教学方法与家庭练习

## 4.1 八个教学环节

| 环节 | 英文 | 家长需要理解什么 |
|---|---|---|
| 1 | Phonemic Awareness | 先听声音，不一定看字母 |
| 2 | Visual Drill | 看字母，快速说发音 |
| 3 | Auditory Drill | 听声音，写出字母 |
| 4 | Blending Drill | 把单个声音合成单词 |
| 5 | New Concept | 学习新的字母或拼读规律 |
| 6 | Word Work | 通过拼读、拼写、替换声音巩固 |
| 7 | Irregular Words | 学习高频词中需要特别关注的拼写 |
| 8 | Connected Text | 把所学规则应用到句子和短文 |

家庭练习不必完整照搬课堂。建议选择2–4个环节，每天10–15分钟。

## 4.2 Word Work Chains（单词变换链）

这是非常值得中国家长借鉴的练习。

### 示例一：替换首音

`mat → sat → pat → bat → cat`

观察：

- m → s
- s → p
- p → b
- b → c

中间的 `at` 保持不变。

### 示例二：替换中间元音

`bat → bet → bit → bot → but`

这条链适合在掌握五个短元音之后使用。其中 bot 是较少见的基础词，可将它作为拼读练习词，而不必重点记忆词义。

### 示例三：替换末音

`map → mat → man → mad`

每次只改变最后一个音。

### 示例四：综合变化

`map → mat → sat → sit → sip → tip → tin`

家长可以按照以下顺序操作：

1. 先让孩子读出第一个单词。
2. 说出需要替换的声音。
3. 让孩子指出哪个位置发生变化。
4. 孩子使用字母卡片完成替换。
5. 重新拼读整个单词。
6. 最后尝试不看字母卡片，直接听写。

**关键不是让孩子记住整条单词链，而是理解每一次声音和拼写如何变化。**

---

## 4.3 Heart Words（需要特别记忆拼写部分的高频词）

有些常见单词包含尚未学过或不符合常见拼读规律的拼写。

例如：

- said
- the
- was
- one
- some

UFLI 的 Heart Words 教学通常会帮助孩子区分：

- 哪些部分可以按照已学规律拼读；
- 哪些部分需要特别关注并记忆。

例如 said：

- s 通常表示 /s/。
- d 通常表示 /d/。
- ai 在 said 中表示 /ɛ/，不同于 rain 中的 /eɪ/。

因此，孩子不必把 said 当作完全无法分析的整体图形来记忆。

**与中文识字对比：**

学习汉字时，孩子可能利用形声字的声旁猜测读音，但也会遇到声旁不能准确提示现代读音的情况。

英语自然拼读同样是利用规律辅助阅读，同时接受规律存在限制。

# Part 5. 阅读与写作练习

## 5.1 从单词到句子

建议遵循：

**字母发音 → VC/CVC 单词 → 简单句子 → 短篇故事**

### Level 1：单词

- mat
- sat
- pin
- sit
- cat

### Level 2：短句

- Sam sat.
- Tim is sad.
- A cat is on a mat.
- The dog can run.

注意：这些句子可能包含孩子尚未系统学习的高频词或拼写模式，应在相应知识已经介绍后使用，或者由家长辅助阅读。

### Level 3：短篇故事

**Sam and the Cat**

Sam has a cat.

The cat sat on a mat.

Sam sat with the cat.

The cat ran.

Sam ran too.

这是一篇家庭补充练习，不是严格限定 Lessons 1–34 已学字素的官方可解码短文。

### 阅读理解问题

- Who has a cat?
- Where did the cat sit?
- What did the cat do?
- Why do you think Sam ran?

前三个问题主要考察事实理解，最后一个问题引导孩子推测人物行为的原因。

---

## 5.2 拼读与阅读理解要同时发展

**会读出单词，不代表理解单词或文章。**

例如，孩子能够准确拼读：

`The cat sat on the mat.`

但家长仍可以进一步问：

- What is a mat?
- Where is the cat?
- Can you draw the cat on the mat?

这与中文阅读类似。

一个孩子即使认识文章里的所有汉字，也不代表一定理解故事的因果关系和人物动机。

因此，自然拼读与阅读理解需要同时发展。

# Part 6. 家长常见问题

### Q1：孩子是不是必须先学国际音标？

不需要。

UFLI 自然拼读主要通过直接学习字母、字母组合与声音的对应关系来建立阅读能力。

国际音标可以帮助家长准确理解发音，但并不是孩子开始自然拼读的先决条件。

### Q2：孩子为什么能读出一个词，却不知道意思？

因为 Decoding（拼读）和 Vocabulary（词汇理解）是不同能力。

例如孩子能拼读 `mug`，但可能不知道它是马克杯。

家长可以展示实物或图片，解释词义，再让孩子用这个词造句。

### Q3：孩子已经认识很多单词，还需要学 Phonics 吗？

需要根据实际能力判断。

如果孩子主要依靠记忆识别熟悉单词，遇到陌生词就无法拼读，说明仍有必要巩固拼读规则。

但如果孩子已经能熟练拼读对应难度的陌生词，就可以逐步增加阅读流利度、词汇和理解练习。

### Q4：为什么同一个字母会有不同发音？

英语拼写保留了不同历史时期和语言来源的痕迹，发音与拼写之间的对应关系比较复杂。

例如：

- cat
- cake
- car
- about

其中 a 的发音不同。

自然拼读教学会先教授常见模式，再逐步扩展。

### Q5：家长英语发音不够标准怎么办？

建议：

1. 优先使用学校或 UFLI 官方音频、视频示范。
2. 家长负责组织练习、鼓励孩子和观察掌握情况。
3. 对不确定的发音，不要仅凭汉语拼音猜测。
4. 遇到困难时，和老师确认当前学习的具体规则。

家长不需要成为英语语音学专家，也能有效帮助孩子复习。
