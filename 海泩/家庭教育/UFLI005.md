# Part 1. 学习目标

完成本单元后，孩子应逐步能够：

- [ ] 认识常见词尾 -es、-ed、-ing。
- [ ] 理解词尾可能改变单词的语法意义。
- [ ] 掌握 -ed 的三种常见发音。
- [ ] 理解 Syllable（音节）的概念。
- [ ] 区分 Closed Syllable（闭合音节）和 Open Syllable（开放音节）。
- [ ] 能尝试将较长单词划分成音节。
- [ ] 能阅读 Closed/Closed 类型的双音节单词。
- [ ] 能阅读 Open/Closed 类型的双音节单词。
- [ ] 能通过词尾和音节结构拼读陌生单词。
- [ ] 能在句子中理解词尾带来的意义变化。

**与 Unit 4 的主要区别：**

Unit 4 主要研究一个单音节词内部的拼写规律：

`cap → cape`

Unit 5 开始研究：

1. **单词如何通过词尾发生变化。**

   `jump → jumped → jumping`

2. **较长的单词如何拆分为多个音节。**

   `rabbit → rab-bit`

# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Suffix（后缀）？

Suffix 是加在词根或基础词后面的词素，可以改变单词的语法形式或意义。

例如：

`jump + ed → jumped`

`jump + ing → jumping`

`box + es → boxes`

### 与中文学习比较

中文通常不通过改变动词本身的拼写来表示过去时。

例如：

- 我跳。
- 我昨天跳了。
- 我正在跳。

英语则经常通过词尾变化表达相关语法意义：

- I jump.
- I jumped.
- I am jumping.

需要注意，英语的 -ed、-ing 并不能与中文“了”“正在”完全一一对应。英语时态和体的表达还涉及助动词及句子结构。

### 家长需要理解

在这一阶段，不必先给孩子讲完整的英语时态体系。

更重要的是帮助孩子发现：

- jump 与 jumped 有共同的基础词。
- 词尾增加后，读音和意义可能发生变化。
- 可以先识别熟悉的基础词，再处理词尾。

---

## 2.2 什么是 Syllable（音节）？

音节是语音中的节奏单位，通常围绕一个元音核心形成。

例如：

| 单词 | 音节划分 | 音节数量 |
|---|---|---:|
| cat | cat | 1 |
| jump | jump | 1 |
| rabbit | rab-bit | 2 |
| sunset | sun-set | 2 |
| robot | ro-bot | 2 |
| banana | ba-na-na | 3 |
| computer | com-pu-ter | 3 |

### 与汉语拼音比较

普通话中，一个汉字通常对应一个音节。

例如：

- 妈妈：mā-ma，两个音节。
- 苹果：píng-guǒ，两个音节。
- 计算机：jì-suàn-jī，三个音节。

英语同样可以将单词拆成音节，但存在明显差异：

**1. 英语一个音节可以包含多个连续辅音。**

例如：

`plant`

虽然有5个字母，但只有一个音节。

**2. 英语音节数量不等于元音字母数量。**

例如：

`cake`

包含 a 和 e 两个元音字母，但只有一个音节。

**3. 英语多音节词存在重音。**

例如：

- RAB-bit
- RO-bot
- ba-NA-na

大写部分表示主要重读音节。

重音会影响元音发音，后续学习多音节词时需要逐渐关注。

---

## 2.3 什么是 Closed Syllable（闭合音节）？

Closed Syllable 通常指以一个或多个辅音音素结尾的音节。

在基础自然拼读教学中，这类音节里的单元音字母通常表示短元音。

例如：

| 单词 | 元音 | 末尾辅音 |
|---|---|---|
| cat | /æ/ | /t/ |
| bed | /ɛ/ | /d/ |
| sit | /ɪ/ | /t/ |
| hot | /ɑ/ | /t/ |
| sun | /ʌ/ | /n/ |

### 双音节例子

`rabbit → rab-bit`

- rab：闭合音节，a 通常发 /æ/。
- bit：闭合音节，i 通常发 /ɪ/。

因此 rabbit 是 Closed/Closed 类型。

### 与汉语拼音比较

普通话拼音中的部分音节可以以鼻音韵尾 -n、-ng 结尾。

但英语闭合音节可以以多种辅音结尾，例如：

- cat
- desk
- milk
- plant

因此，不能直接用汉语拼音的声母、韵母结构判断英语音节类型。

---

## 2.4 什么是 Open Syllable（开放音节）？

Open Syllable 指以元音音素结尾的音节。

在基础自然拼读教学中，开放音节末尾的单个元音字母通常发长元音。

例如：

| 音节 | 常见发音 | 示例 |
|---|---|---|
| me | /mi/ | me |
| he | /hi/ | he |
| hi | /haɪ/ | hi |
| no | /noʊ/ | no |
| go | /goʊ/ | go |

### Closed 与 Open 对比

| 类型 | 示例 | 元音 |
|---|---|---|
| Closed | met | /ɛ/ |
| Open | me | /i/ |
| Closed | not | /ɑ/ |
| Open | no | /oʊ/ |
| Closed | hit | /ɪ/ |
| Open | hi | /aɪ/ |

**核心区别：**

- 闭合音节：音节末尾有辅音。
- 开放音节：音节末尾没有辅音，元音构成音节结尾。

### 家长容易混淆的地方

Open Syllable 和 VCe 都可能产生长元音，但结构不同。

**Open Syllable：**

`go → /goʊ/`

元音直接位于音节末尾。

**VCe：**

`hope → /hoʊp/`

元音后面有辅音，词尾还有不发音的 e。

# Part 4. 逐课知识点与家庭练习

## Lesson 63 — Suffix -es

### 1. 学习目标

认识词尾 -es，并理解它在某些名词复数和动词形式中的作用。

### 2. 示例单词

| 基础词 | 添加 -es | 意思 |
|---|---|---|
| box | boxes | 盒子（复数） |
| bus | buses | 公共汽车（复数） |
| dish | dishes | 盘子（复数） |
| wish | wishes | 愿望（复数） |
| fox | foxes | 狐狸（复数） |
| bench | benches | 长椅（复数） |

### 3. 发音规律

在这些例子中，-es 通常读 /ɪz/，形成一个新的音节。

例如：

`box → /bɑks/`

`boxes → /ˈbɑk.sɪz/`

boxes 有两个音节。

### 4. 为什么有时加 -s，有时加 -es？

比较：

- cat → cats
- dog → dogs
- box → boxes
- dish → dishes

当单词以 /s/、/z/、/ʃ/、/ʒ/、/tʃ/、/dʒ/ 等咝音结尾时，复数通常需要增加 /ɪz/ 音节。

在基础拼写中，这经常对应添加 -es。

但英语拼写还存在其他复数规则，例如 baby → babies，后续会进一步学习。

### 5. 与中文比较

中文名词通常不通过增加词尾表示复数：

- 一个盒子
- 两个盒子

英语则需要区分：

- one box
- two boxes

### 6. 家庭练习

**分类**

将以下词分成两组：

cats, dogs, boxes, dishes, cups, wishes

**听写**

- boxes
- buses
- dishes
- wishes

**句子**

- I have two boxes.
- The dishes are clean.
- She wishes for a dog.

### 7. 常见错误

- 将 boxes 读成 box-s，而没有 /ɪ/。
- 把 -es 一律读成 /ɛs/。
- 认为所有复数都需要添加 -es。

## Lesson 64 — Suffix -ed

### 1. 学习目标

掌握规则动词词尾 -ed 的三种常见发音：

- /t/
- /d/
- /ɪd/

### 2. 示例单词

| 发音 | 示例 |
|---|---|
| /t/ | jumped, helped, washed, kicked |
| /d/ | played, cleaned, called, opened |
| /ɪd/ | wanted, needed, landed, started |

### 3. 为什么 -ed 有三种发音？

主要由基础词最后一个音素决定。

**情况一：/t/**

如果基础词以 /t/、/d/ 之外的清辅音结尾，-ed 通常发 /t/。

例如：

`jump → jumped`

读作 /dʒʌmpt/。

**情况二：/d/**

如果基础词以元音或 /t/、/d/ 之外的浊辅音结尾，-ed 通常发 /d/。

例如：

`play → played`

读作 /pleɪd/。

**情况三：/ɪd/**

如果基础词以 /t/ 或 /d/ 结尾，-ed 通常发 /ɪd/，增加一个音节。

例如：

`want → wanted`

读作 /ˈwɑn.tɪd/（常见美式发音）。

### 4. 与中文比较

中文可以通过时间词或助词表达过去发生的动作：

- 我昨天跳了。
- 我昨天玩了。

英语常用过去式：

- I jumped yesterday.
- I played yesterday.

但 -ed 不只用于一般过去时，也可以出现在过去分词等形式中。

### 5. 家庭练习

**发音分类**

将以下单词按 /t/、/d/、/ɪd/ 分类：

jumped, played, wanted, helped, cleaned, needed, kicked, called

**听音判断**

家长读：

- jumped
- played
- wanted

孩子判断词尾发音是否增加一个音节。

### 6. 常见错误

- 把所有 -ed 都读成 /ɪd/。
- 只根据最后一个字母，而不是最后一个音素判断发音。
- 将 jumped 读成 jump-ed 两个音节。

## Lesson 65 — Suffix -ing

### 1. 学习目标

认识 -ing 词尾，学习将它与基础词组合。

### 2. 示例单词

| 基础词 | 添加 -ing |
|---|---|
| jump | jumping |
| help | helping |
| sing | singing |
| look | looking |
| wish | wishing |
| play | playing |

### 3. 发音解释

-ing 通常读 /ɪŋ/。

例如：

`jumping → /ˈdʒʌm.pɪŋ/`

通常有两个音节：

`jump-ing`

注意 ng 在这里通常表示 /ŋ/，不是 /n/ + /g/。

### 4. -ing 表示什么？

-ing 可以出现在不同的语法结构中。

例如：

**进行时：**

- I am jumping.
- She is reading.

**动名词：**

- Swimming is fun.
- I like reading.

对一年级孩子来说，重点是认识词尾、正确拼读和理解常见句子，不必立即系统学习全部语法用途。

### 5. 与中文比较

中文：

“我正在跳。”

英语：

“I am jumping.”

但不能简单理解为 -ing 就等于“正在”，因为英语进行时还需要相应的 be 动词。

### 6. 家庭练习

**拼读**

- jumping
- helping
- singing
- wishing
- looking

**句子**

- The dog is jumping.
- The boy is singing.
- I am helping Mom.

### 7. 常见错误

- 将 -ing 读成 /ɪn/。
- 将 ng 读成两个独立音素 /n/ + /g/。
- 认为所有动词加 -ing 都不需要改变拼写。

例如：

- make → making（去掉 e）
- run → running（双写 n）

这些属于后续的拼写变化规则，本课可以简单介绍，不必要求全部掌握。

## Lesson 66 — Closed & Open Syllables

### 1. 学习目标

能够区分闭合音节与开放音节，并理解它们与元音发音之间的常见关系。

### 2. Closed Syllables

| 音节 | 元音 |
|---|---|
| cat | /æ/ |
| bed | /ɛ/ |
| sit | /ɪ/ |
| hot | /ɑ/ |
| sun | /ʌ/ |

### 3. Open Syllables

| 音节 | 元音 |
|---|---|
| me | /i/ |
| hi | /aɪ/ |
| no | /oʊ/ |
| go | /oʊ/ |
| she | /i/ |

### 4. 为什么需要学习音节类型？

因为英语单词变长以后，孩子不能只靠从头到尾逐个字母拼读。

例如：

`robot`

可以分成：

`ro-bot`

其中：

- ro 是开放音节，o 通常发 /oʊ/。
- bot 是闭合音节，o 通常发短元音 /ɑ/。

### 5. 家庭练习

**分类**

将以下单词或音节分成 Open 和 Closed：

cat, me, sit, go, bed, hi, sun, no

**听写**

- me
- hi
- no
- cat
- bed

### 6. 常见错误

- 认为开放音节一定是单字母。
- 认为闭合音节一定只有三个字母。
- 认为所有开放音节都没有例外地发长元音。

## Lesson 67 — Closed/Closed Syllable Division

### 1. 学习目标

学习两个闭合音节组成的单词。

### 2. 示例单词

| 单词 | 音节划分 | 中文 |
|---|---|---|
| rabbit | rab-bit | 兔子 |
| napkin | nap-kin | 餐巾 |
| basket | bas-ket | 篮子 |
| picnic | pic-nic | 野餐 |
| sunset | sun-set | 日落 |
| muffin | muf-fin | 松饼 |
| dentist | den-tist | 牙医 |

### 3. 如何阅读 rabbit？

第一步：找到元音字母 a、i。

第二步：尝试将单词分为两个音节：

`rab-bit`

第三步：分别拼读：

- rab → /ræb/
- bit → /bɪt/

第四步：合起来：

`rabbit → /ˈræbɪt/`

### 4. Closed/Closed 的特点

两个音节都以辅音结尾。

例如：

`nap-kin`

- nap：闭合音节。
- kin：闭合音节。

两个元音通常都发短元音。

### 5. 与中文拼音比较

中文拼音中，一个音节通常对应一个汉字。

英语则可能在一个单词内部包含两个或更多音节。

例如：

rabbit 是一个英语单词，但有两个音节。

### 6. 家庭练习

**音节划分**

- rabbit
- napkin
- basket
- picnic
- sunset

**阅读步骤**

1. 找出元音。
2. 尝试划分音节。
3. 分别拼读。
4. 合成完整单词。
5. 检查读音是否是熟悉的词。

### 7. 常见错误

- 将 rabbit 当成一个很长的单音节词。
- 把 rabbit 拆成 ra-bbit 并按开放音节规则误读。
- 认为所有双音节单词都必须在两个辅音字母中间划分。

音节划分是帮助阅读的策略，实际英语发音和词典音节划分可能存在差异。

## Lesson 68 — Open/Closed Syllable Division

### 1. 学习目标

学习第一个音节开放、第二个音节闭合的双音节单词。

### 2. 示例单词

| 单词 | 音节划分 | 中文 |
|---|---|---|
| robot | ro-bot | 机器人 |
| hotel | ho-tel | 酒店 |
| moment | mo-ment | 时刻 |
| music | mu-sic | 音乐 |
| basic | ba-sic | 基础的 |
| unit | u-nit | 单元 |
| tulip | tu-lip | 郁金香 |

### 3. 如何阅读 robot？

第一步：找到两个元音字母 o、o。

第二步：尝试划分：

`ro-bot`

第三步：分析音节：

- ro：开放音节，o 发 /oʊ/。
- bot：闭合音节，o 发 /ɑ/。

第四步：合成：

`robot → /ˈroʊ.bɑt/`

### 4. 与 Closed/Closed 对比

| 类型 | 示例 | 第一个音节 | 第二个音节 |
|---|---|---|---|
| Closed/Closed | rabbit | rab | bit |
| Closed/Closed | napkin | nap | kin |
| Open/Closed | robot | ro | bot |
| Open/Closed | hotel | ho | tel |

### 5. 家庭练习

**分类**

将以下单词分成两组：

rabbit, robot, napkin, hotel, picnic, music, basket, tulip

**阅读步骤**

1. 找到元音字母。
2. 尝试划分音节。
3. 判断每个音节是开放还是闭合。
4. 根据音节类型尝试读出单词。
5. 将音节合成为完整单词。
6. 根据熟悉的口语词汇或词典发音检查结果。

### 6. 常见错误

- 认为所有双音节单词都应该在两个辅音中间分开。
- 忽略第一个开放音节中的长元音。
- 认为音节划分规则可以准确预测所有英语单词的发音。

# Part 5. UFLI 教学方法与家庭练习

## 5.1 八个教学环节

| 环节 | 目标 | 家庭活动 |
|---|---|---|
| Phonemic Awareness | 听辨音素 | 听 jumped 的词尾发音 |
| Visual Drill | 看字母或模式说发音 | 复习元音及常见词尾 |
| Auditory Drill | 听音写拼写 | 听 /ɪz/、/t/、/d/ |
| Blending Drill | 合成声音 | /r/ /æ/ /b/ → rab |
| New Concept | 学习新规则 | 讲解 -ed 或音节类型 |
| Word Work | 拼读与拼写 | 基础词加后缀 |
| Irregular Words | 特殊高频词 | 复习学校当周 Heart Words |
| Connected Text | 阅读应用 | 阅读双音节词与短文 |

## 5.2 每天15分钟练习

### Step 1：词尾发音（3分钟）

家长读：

- boxes
- jumped
- played
- wanted
- jumping

孩子判断词尾增加了什么声音，是否增加一个音节。

### Step 2：音节划分（4分钟）

准备：

- rabbit
- napkin
- robot
- hotel

让孩子尝试划分音节并读出来。

### Step 3：Word Work（4分钟）

使用基础词与后缀卡片：

`jump + ed → jumped`

`jump + ing → jumping`

`box + es → boxes`

### Step 4：句子阅读（4分钟）

- The rabbit is jumping.
- We had a picnic.
- The robot is in the room.
- The boy wanted a snack.

这些句子包含部分尚未学习的拼写规则，可以由家长辅助阅读。

# Part 6. 阅读与写作练习

## 6.1 阅读短文：The Robot

Tom has a robot.

The robot can jump.

Tom wanted the robot to help him.

The robot picked up a box.

Then it jumped on the bed.

Tom was happy.

# Part 7. 中国家长常见问题

### Q1：孩子需要学习英语语法才能理解 -ed、-ing 吗？

不需要先系统学习完整语法。

可以通过具体句子理解词尾与意义的联系。

### Q2：为什么 jumped 的 -ed 不读 /ɪd/？

因为 jump 以清辅音 /p/ 结尾，-ed 通常读 /t/。

### Q3：为什么 wanted 有两个音节，而 jumped 只有一个？

wanted 的 -ed 读 /ɪd/，增加一个音节。

jumped 的 -ed 读 /t/，通常不增加音节。

### Q4：为什么 robot 要分成 ro-bot？

因为第一个音节 ro 是开放音节，o 通常发长元音 /oʊ/。

第二个音节 bot 是闭合音节，o 通常发短元音。

### Q5：是不是所有单词都能按音节规则正确拼读？

不是。

音节类型与划分策略能帮助孩子预测常见拼写模式，但英语存在重音、弱读、历史拼写及其他例外。

### Q6：家长应该让孩子背诵音节划分规则吗？

不建议以机械背诵为主。

更有效的方式是让孩子实际练习：

1. 找元音。
2. 尝试划分音节。
3. 分别拼读。
4. 合成单词。
5. 检查读音和词义。

# Part 10. 本单元总结

## 三个最重要的学习成果

**1. 理解单词可以通过后缀发生变化。**

例如：

- box → boxes
- jump → jumped
- jump → jumping

**2. 理解较长单词可以拆分成音节。**

例如：

- rabbit → rab-bit
- robot → ro-bot

**3. 能够利用音节类型辅助拼读陌生单词。**

例如：

- Closed/Closed：rabbit
- Open/Closed：robot
