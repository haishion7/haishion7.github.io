# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Diphthong（双元音）？

Diphthong 指在一个音节内部，发音从一个元音音质滑向另一个元音音质的现象。

例如：

`boy → /bɔɪ/`

其中 /ɔɪ/ 是一个双元音。

发音时：

1. 从 /ɔ/ 附近的元音位置开始。
2. 舌头逐渐向 /ɪ/ 的方向移动。
3. 整个过程连续完成。

虽然 /ɔɪ/ 的音质发生了变化，但在英语音素分析中通常将它作为一个元音音素。

### 例子一：boy

- b → /b/
- oy → /ɔɪ/

所以：

- 字母数量：3
- 音素数量：2
- 音节数量：1

### 例子二：coin

- c → /k/
- oi → /ɔɪ/
- n → /n/

所以：

- 字母数量：4
- 音素数量：3
- 音节数量：1

### 例子三：cloud

- c → /k/
- l → /l/
- ou → /aʊ/
- d → /d/

所以：

- 字母数量：5
- 音素数量：4
- 音节数量：1

**核心结论：双元音不等于两个音节。**

---

## 2.2 与汉语拼音复韵母的比较

汉语拼音也有复韵母，例如：

- ai
- ei
- ao
- ou

这些韵母同样涉及元音音质的变化，因此可以帮助中国家长理解英语双元音的基本概念。

例如：

| 英语双元音 | 示例 | 汉语拼音参考 | 注意 |
|---|---|---|---|
| /ɔɪ/ | boy, coin | 没有完全对应的常见复韵母 | 需要单独练习 |
| /aʊ/ | cow, house | ao 有一定相似性 | 发音起点和滑动方式可能不同 |
| /aɪ/ | pie, light | ai | 已在前面单元学习 |
| /eɪ/ | rain, play | ei | 已在前面单元学习 |
| /oʊ/ | boat, snow | ou | 已在前面单元学习 |

### 为什么不能直接用汉语拼音替代？

虽然部分声音听起来相似，但两种语言的元音音质、滑动方向和发音习惯可能不同。

例如：

- 英语 cow 中的 /aʊ/ 不完全等于拼音 ao。
- 英语 boy 中的 /ɔɪ/ 没有一个可以直接替代的普通话拼音韵母。

家长可以使用汉语拼音帮助理解概念，但应使用英语音频学习实际发音。

---

## 2.3 双元音与 Vowel Team 有什么关系？

在自然拼读教学中，Vowel Team 指多个字母共同表示元音的拼写模式。

例如：

- ai → /eɪ/
- ee → /i/
- oa → /oʊ/
- oi → /ɔɪ/
- ou → /aʊ/

但需要区分：

**Vowel Team 是拼写概念。**

**Diphthong 是语音概念。**

例如：

`ee → /i/`

ee 是 Vowel Team，但 /i/ 通常是单元音（Monophthong）。

`oi → /ɔɪ/`

oi 是 Vowel Team，而 /ɔɪ/ 是双元音。

### 为什么 UFLI 单独安排 Diphthongs 单元？

因为 oi、oy、ou、ow 等组合具有相对独立的拼写规律。

将它们单独学习，有助于孩子进行分类、比较和拼写练习。

---

## 2.4 为什么同一个双元音有不同拼写？

例如：

- coin
- boy

两者都包含 /ɔɪ/，但拼写不同。

再例如：

- cloud
- cow

两者都包含 /aʊ/，但拼写不同。

| 发音 | 拼写 | 示例 |
|---|---|---|
| /ɔɪ/ | oi | coin, soil |
| /ɔɪ/ | oy | boy, toy |
| /aʊ/ | ou | cloud, house |
| /aʊ/ | ow | cow, brown |

这与之前学习的 ai/ay、oa/ow 很相似。

### 常见位置规律

| 拼写 | 常见位置 |
|---|---|
| oi | 单词或音节内部 |
| oy | 单词或音节末尾 |
| ou | 单词内部 |
| ow | 单词或音节末尾，也可出现在词中 |

这些是常见倾向，不是绝对规则。

# Part 4. 逐课知识点与家庭练习

## Lesson 95 — oi、oy /ɔɪ/

### 1. 学习目标

学习 `oi` 和 `oy` 通常表示双元音 /ɔɪ/。

**核心规律：**

- oi 经常出现在单词内部。
- oy 经常出现在单词末尾或音节末尾。

### 2. 示例单词

**oi**

| 单词 | 中文 |
|---|---|
| coin | 硬币 |
| soil | 土壤 |
| oil | 油 |
| boil | 煮沸 |
| join | 加入 |
| point | 点；指向 |
| noise | 噪声 |
| voice | 声音 |
| choice | 选择 |
| spoil | 破坏；宠坏 |
| avoid | 避免 |
| toilet | 厕所 |

**oy**

| 单词 | 中文 |
|---|---|
| boy | 男孩 |
| toy | 玩具 |
| joy | 快乐 |
| soy | 大豆 |
| enjoy | 享受 |
| annoy | 使烦恼 |
| destroy | 破坏 |
| cowboy | 牛仔 |
| royal | 皇家的 |
| oyster | 牡蛎 |

部分较长单词包含后续才系统学习的拼写或音节模式，适合作为扩展词汇。

### 3. 发音解释

**coin**

`/k/ + /ɔɪ/ + /n/ → coin`

**boy**

`/b/ + /ɔɪ/ → boy`

**point**

`/p/ + /ɔɪ/ + /n/ + /t/ → point`

注意：

- oi、oy 都表示一个双元音。
- 不需要把 o 和 i、o 和 y 分别读成两个音节。

### 4. oi 与 oy 的拼写位置

| 拼写 | 常见位置 | 示例 |
|---|---|---|
| oi | 词中 | coin, point, soil |
| oy | 词尾 | boy, toy, joy |
| oy | 音节末尾 | enjoy, cowboy |

例如：

- coin 通常不写成 coyn。
- boy 通常不写成 boi。
- point 通常不写成 poynt。

这些错误拼写仅用于说明位置规律，不应作为孩子的正式练习词。

### 5. 与汉语拼音比较

/ɔɪ/ 没有完全对应的常见普通话复韵母。

发音时可以先从接近 /ɔ/ 的位置开始，再滑向 /ɪ/。

不要把 boy 读成两个独立的元音音节。

### 6. 家庭练习

**音素分割**

- boy → /b/ /ɔɪ/
- coin → /k/ /ɔɪ/ /n/
- soil → /s/ /ɔɪ/ /l/
- point → /p/ /ɔɪ/ /n/ /t/
- spoil → /s/ /p/ /ɔɪ/ /l/

**Word Chains**

Chain A：

`boy → toy → joy → soy`

每一步改变首辅音。

Chain B：

`coin → join → joint → point`

其中：

- coin → join：替换首辅音。
- join → joint：增加末辅音 /t/。
- joint → point：替换首辅音。

Chain C：

`soil → boil → foil → toil`

每一步改变首辅音。

**拼写分类**

将以下单词分成 oi、oy 两组：

coin, boy, soil, toy, point, joy, join, enjoy, oil, cowboy

**听写**

基础组：

- boy
- toy
- coin
- oil
- soil

进阶组：

- point
- join
- spoil
- enjoy
- choice

### 7. 家长常见错误

- 将 oi 按汉语拼音 oi 猜测发音。
- 将 oi、oy 拆成两个音节。
- 认为 oi、oy 可以在任何位置随意替换。
- 认为所有包含 oy 的单词都只有一个音节。

例如 cowboy 有两个音节：cow-boy。

## Lesson 96 — ou、ow /aʊ/

### 1. 学习目标

学习 `ou` 和 `ow` 表示双元音 /aʊ/ 的常见规律。

### 2. 示例单词

**ou**

| 单词 | 中文 |
|---|---|
| out | 外面 |
| loud | 大声的 |
| cloud | 云 |
| house | 房子 |
| mouse | 老鼠 |
| round | 圆的 |
| sound | 声音 |
| found | 找到（过去式） |
| count | 数数 |
| shout | 大喊 |
| mouth | 嘴巴 |
| ground | 地面 |
| proud | 骄傲的 |

**ow**

| 单词 | 中文 |
|---|---|
| cow | 奶牛 |
| now | 现在 |
| how | 怎样 |
| brown | 棕色 |
| down | 向下 |
| town | 城镇 |
| clown | 小丑 |
| crown | 王冠 |
| owl | 猫头鹰 |
| flower | 花 |
| power | 力量 |
| towel | 毛巾 |

### 3. 发音解释

**cow**

`/k/ + /aʊ/ → cow`

**cloud**

`/k/ + /l/ + /aʊ/ + /d/ → cloud`

**house**

`/h/ + /aʊ/ + /s/ → house`

注意：

- ou 在 cloud 中表示一个双元音。
- ow 在 cow 中表示一个双元音。
- house 的末尾 e 不单独发音。

### 4. ou 与 ow 的常见位置规律

| 拼写 | 常见位置 | 示例 |
|---|---|---|
| ou | 词中 | cloud, round, shout |
| ow | 词尾 | cow, now, how |
| ow | 词中 | brown, down, town |

与 ai/ay、oi/oy 相比，ou/ow 的位置规律没有那么简单。

例如：

- brown 的 ow 位于词中。
- cloud 的 ou 位于词中。
- cow 的 ow 位于词尾。

因此，家长应把位置规律作为辅助，而不是绝对拼写规则。

### 5. 与汉语拼音比较

英语 /aʊ/ 与汉语拼音 ao 有一定听觉相似性。

但二者的发音起点和滑动方式可能不同。

例如：

- cow
- now
- house

都应作为一个音节或单词中的一个元音核心来发音，不要将 /aʊ/ 拆成两个独立音节。

### 6. 特别重要：ow 的两种发音

在 Unit 8 中，孩子已经学习：

`ow → /oʊ/`

例如：

- snow
- grow
- slow
- show

现在学习：

`ow → /aʊ/`

例如：

- cow
- now
- brown
- down

### 综合比较

| ow /oʊ/ | ow /aʊ/ |
|---|---|
| snow | cow |
| grow | now |
| slow | how |
| show | brown |
| blow | down |

**家长需要强调：同一个字母组合 ow 可以有两种常见发音。**

遇到陌生单词时，可以根据已学词汇、拼写模式和上下文尝试判断。

### 7. ou 的其他发音

ou 也不总是表示 /aʊ/。

例如：

| 单词 | ou 的发音 |
|---|---|
| out | /aʊ/ |
| cloud | /aʊ/ |
| soup | /u/ |
| group | /u/ |
| young | /ʌ/ |
| touch | /ʌ/ |
| four | /ɔr/（常见美式英语） |

本课先学习 ou /aʊ/，其他情况作为扩展知识。

### 8. 家庭练习

**音素分割**

- cow → /k/ /aʊ/
- now → /n/ /aʊ/
- cloud → /k/ /l/ /aʊ/ /d/
- shout → /ʃ/ /aʊ/ /t/
- brown → /b/ /r/ /aʊ/ /n/

**Word Chains**

Chain A：

`cow → how → now → bow`

这里 bow 应明确指“鞠躬”，读 /baʊ/；作为“蝴蝶结”时读 /boʊ/。

Chain B：

`down → town → gown → frown`

其中 gown → frown 同时增加并改变辅音，不属于严格单步变化。

推荐拆成：

`down → town → gown`

以及：

`brown → frown → crown`

Chain C：

`loud → cloud → clout → shout`

其中 cloud → clout 改变末辅音，clout → shout 同时改变多个辅音，因此适合作为综合拼读比较，而非完整的单步链。

**拼写分类**

将以下单词分成 ou、ow：

cow, cloud, now, house, brown, round, shout, down, mouse, town

**听写**

基础组：

- cow
- now
- out
- loud
- down

进阶组：

- cloud
- house
- brown
- shout
- round

### 9. 家长常见错误

- 将 ou、ow 拆成两个独立元音。
- 将 cow 读成 snow 中的 /oʊ/。
- 认为 ow 只有一种发音。
- 认为 ou 在所有单词中都表示 /aʊ/。
- 将 house 末尾 e 单独读出来。

## Lesson 97 — Vowel Teams & Diphthongs Review

### 1. 学习目标

综合复习之前学习的 Vowel Teams 与本单元的 Diphthongs。

重点包括：

- ai、ay → /eɪ/
- ee、ea、ey → /i/
- oa、ow、oe → /oʊ/
- ie、igh → /aɪ/
- oo → /ʊ/ 或 /u/
- ew、ui、ue → /u/
- au、aw、augh → /ɔ/
- oi、oy → /ɔɪ/
- ou、ow → /aʊ/

### 2. 综合知识表

| 发音 | 常见拼写 | 示例 |
|---|---|---|
| /eɪ/ | ai、ay | rain, play |
| /i/ | ee、ea、ey | see, team, key |
| /oʊ/ | oa、ow、oe | boat, snow, toe |
| /aɪ/ | ie、igh | pie, light |
| /ʊ/ | oo、u | book, put |
| /u/ | oo、ew、ui、ue | moon, grew, fruit, blue |
| /ɔ/ | au、aw、augh | August, saw, caught |
| /ɔɪ/ | oi、oy | coin, boy |
| /aʊ/ | ou、ow | cloud, cow |

### 3. 重点对比：ow 的两种发音

**/oʊ/**

- snow
- grow
- slow
- show

**/aʊ/**

- cow
- now
- brown
- down

### 4. 重点对比：ou 与 oo

| 单词 | 拼写 | 发音 |
|---|---|---|
| moon | oo | /u/ |
| book | oo | /ʊ/ |
| soup | ou | /u/ |
| cloud | ou | /aʊ/ |

这说明英语拼写与发音存在多对多的对应关系。

### 5. 综合听音分类

家长读：

coin, boy, cloud, cow, snow, boat, moon, book, rain, light

- /ɔɪ/
- /aʊ/
- /oʊ/
- /u/
- /ʊ/
- /eɪ/
- /aɪ/

### 6. 综合 Word Chains

**Chain B — /ɔɪ/**

`coin → join → joint → point`

**Chain C — /aʊ/**

`cow → how → now`

**Chain D — /aʊ/**

`down → town → gown`

**Chain E — /oʊ/**

`boat → coat → goat → moat`

### 7. 综合听写

**基础组**

- boy
- coin
- cow
- now
- cloud

**进阶组**

- point
- join
- brown
- shout

**挑战组**

# Part 5. UFLI 教学方法与家庭练习

## 5.1 八个教学环节

| UFLI 环节 | 学习目标 | 家庭练习 |
|---|---|---|
| Phonemic Awareness | 听辨双元音 | coin / cow |
| Visual Drill | 看字母组合说发音 | oi、oy、ou、ow |
| Auditory Drill | 听音选择拼写 | 听 /ɔɪ/，讨论 oi、oy |
| Blending Drill | 合成声音 | /k/ /ɔɪ/ /n/ → coin |
| New Concept | 学习新规则 | 解释 oi 与 oy 的位置规律 |
| Word Work | 拼读、拼写和变换 | coin → join → joint |
| Irregular Words | 学习特殊高频词 | 复习学校当周 Heart Words |
| Connected Text | 阅读应用 | 阅读包含双元音的句子与短文 |

### 特别提醒：Auditory Drill

听到 /ɔɪ/ 时，孩子不能仅凭声音确定应该写 oi 还是 oy。

可以结合单词位置：

- coin：oi 位于词中。
- boy：oy 位于词尾。

同样，听到 /aʊ/ 时，也不能仅凭声音确定 ou 或 ow。

因此，**拼读规律与词汇拼写记忆需要共同发展。**

## 5.2 每天15分钟家庭练习

### Step 1：听音辨别（3分钟）

家长读：

- boy
- coin
- cow
- cloud
- snow

孩子判断包含：

- /ɔɪ/
- /aʊ/
- /oʊ/

### Step 2：拼写模式卡片（3分钟）

展示：

- oi
- oy
- ou
- ow

孩子说出常见发音，并举出一个单词。

对于 ow，应允许孩子回答 /oʊ/ 和 /aʊ/ 两种已学发音。

### Step 3：Word Chains（5分钟）

例如：

`coin → join → joint → point`

让孩子指出每一步变化的声音。

### Step 4：句子阅读（4分钟）

- The boy has a toy.
- I found a coin.
- The cow is brown.
- The cloud is big.
- We can shout out loud.

这些句子包含部分其他拼写模式或高频词，可以由家长辅助阅读。

**The Boy and the Brown Cow**

A boy had a toy.

He went to a farm.

He saw a brown cow.

The cow was loud.

The boy found a coin on the ground.

He put the coin in his pocket.

Then he went home.

> 本文用于家庭阅读理解练习，并非严格限定 Lessons 1–97 已学规则的官方 Decodable Text。went、saw、pocket 等词可能需要家长辅助。

1. What did the boy have?
2. Where did the boy go?
3. What color was the cow?
4. What did the boy find?

前4个问题侧重事实理解，第5个问题引导推理，第6个问题练习故事复述。

# Part 7. 中国家长常见问题

### Q1：为什么 boy 只有一个音节？

因为 oy 表示一个双元音 /ɔɪ/。

boy 的音素是 /b/ 和 /ɔɪ/，一共两个音素，但只有一个音节。

### Q2：为什么 coin 有4个字母，却只有3个音素？

因为 oi 共同表示一个双元音 /ɔɪ/。

coin 的音素是 /k/、/ɔɪ/、/n/。

### Q3：为什么 cow 和 snow 中的 ow 发音不同？

因为 ow 有两种常见发音：

- cow：/aʊ/
- snow：/oʊ/

需要结合拼写模式、词汇和上下文判断。

### Q4：为什么 coin 使用 oi，而 boy 使用 oy？

因为 oi 经常出现在单词内部，oy 经常出现在词尾。

但这只是常见拼写规律，不是绝对规则。

### Q5：为什么 cloud 和 cow 的元音相同，拼写却不同？

因为 ou 和 ow 都可以表示 /aʊ/。

英语同一个音素可能有不同拼写。

### Q6：双元音是不是两个元音音素？

在本单元的英语音素教学中，/ɔɪ/ 和 /aʊ/ 各作为一个元音音素。

它们虽然包含元音音质的变化，但并不是两个独立音节。

### Q7：家长可以直接用汉语拼音 ao 教 /aʊ/ 吗？

不建议直接替代。

可以借助复韵母的概念帮助理解，但实际发音应以英语示范为准。

### Q8：孩子需要背诵所有 oi、oy、ou、ow 单词吗？

不需要。

建议：

1. 先掌握常见发音。
2. 理解拼写位置规律。
3. 练习拼读陌生单词。
4. 通过阅读积累准确拼写。
5. 对容易混淆的词进行分类练习。

# Part 10. 本单元总结

## 三个最重要的学习成果

**1. 理解双元音是一个音节中的元音音质变化。**

例如：

- boy → /bɔɪ/
- cow → /kaʊ/

**2. 掌握同一个双元音的不同拼写。**

例如：

- /ɔɪ/：coin、boy
- /aʊ/：cloud、cow

**3. 理解同一个字母组合可能有不同发音。**

例如：

- snow：ow → /oʊ/
- cow：ow → /aʊ/

## 下一单元预告

**Unit 11 — Silent Letters（不发音的字母，Lesson 98）**

官方 Lesson 98 主要学习：

- kn → /n/
- wr → /r/
- mb → /m/

例如：

- knee、knife、know
- write、wrong、wrist
- lamb、comb、thumb

下一单元的核心概念是：

**英语单词中有些字母虽然保留在拼写中，但在现代英语发音中不再单独发音。**

例如：

- knee 中的 k 不发音。
- write 中的 w 不发音。
- lamb 中的 b 不发音。

这也是英语拼写历史与现代发音之间差异的一个典型体现。
