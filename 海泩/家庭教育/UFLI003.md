# Part 2. 中国家长需要理解的基础概念

## 2.1 Digraph 与 Blend 的区别

### Digraph：两个字母共同表示一个音素

例如：

`sh → /ʃ/`

在 ship 中：

- sh → /ʃ/
- i → /ɪ/
- p → /p/

所以 ship 有3个音素。

其他例子：

- ch → /tʃ/：chin
- th → /θ/：thin
- ph → /f/：phone
- ck → /k/：duck

### Blend：多个辅音音素连续出现

例如：

`st → /s/ + /t/`

在 stop 中：

- s → /s/
- t → /t/
- o → /ɑ/
- p → /p/

所以 stop 有4个音素。

| 类型 | 字母组合 | 音素 | 示例 |
|---|---|---|---|
| Digraph | sh | /ʃ/ | ship |
| Digraph | ch | /tʃ/ | chin |
| Digraph | th | /θ/ | thin |
| Digraph | ck | /k/ | duck |
| Blend | st | /s/ + /t/ | stop |
| Blend | bl | /b/ + /l/ | black |
| Blend | tr | /t/ + /ɹ/ | trip |
| Blend | fl | /f/ + /l/ | flag |

### 与汉语拼音比较

汉语拼音中的 zh、ch、sh 也由两个字母组成，但每组表示一个声母。

例如：

`sh + a → sha`

这可以帮助家长理解“多个字母共同表示一个声音”。

但要注意：

- 拼音 sh 不等于英语 sh。
- 拼音 ch 不等于英语 ch。
- 英语 th 的两个常见发音，在普通话中都没有完全对应的音素。

**家长不要直接用汉语拼音的发音代替英语字母组合。**

---

## 2.2 为什么英语需要两个字母表示一个音？

英语有26个字母，但英语音素的数量多于26个。

因此，英语使用单个字母、多个字母组合等方式来表示不同音素。

例如：

| 音素 | 常见拼写 | 示例 |
|---|---|---|
| /ʃ/ | sh | ship |
| /tʃ/ | ch | chin |
| /θ/ | th | thin |
| /ð/ | th | this |
| /ŋ/ | ng | sing |
| /f/ | f、ph | fish、phone |
| /k/ | c、k、ck | cat、kit、duck |

这也是自然拼读必须逐步学习的原因：同一个音素可能有不同拼写，同一种字母组合也可能有不同读音。

# Part 4. 逐课知识点与家庭练习

## Lesson 42 — FLSZ Spelling Rule

### 1. 学习目标

学习英语中的一种常见拼写规律：

**在许多单音节、短元音结尾接 /f/、/l/、/s/、/z/ 的单词中，最后一个辅音字母通常双写。**

也称为 Floss Rule。

### 2. 示例单词

| 词尾 | 示例 |
|---|---|
| ff | off, puff, cliff, staff |
| ll | bell, hill, doll, fill |
| ss | miss, kiss, class, dress |
| zz | buzz, fuzz |

比较：

- fill：两个 l 通常仍表示一个 /l/。
- miss：两个 s 通常仍表示一个 /s/。
- buzz：两个 z 通常仍表示一个 /z/。

### 3. 家长需要理解

双写辅音并不代表要把辅音发两遍。

例如：

`bell → /b/ /ɛ/ /l/`

虽然有两个 l，但只有一个 /l/ 音素。

**与汉语拼音对比：**

汉语拼音通常不会通过双写同一个声母来表示这样的单音节词尾拼写规律。

英语这里的双写主要是一种正字法（Spelling Convention），不是要求重复发音。

### 4. 家庭练习

**听写**

- bell
- hill
- miss
- puff
- buzz

**音素分割**

- bell → /b/ /ɛ/ /l/
- miss → /m/ /ɪ/ /s/
- puff → /p/ /ʌ/ /f/

**Word Chain**

`bell → bill → fill → fall`

每一步替换一个音素，注意 fall 使用 Lesson 43 即将学习的特殊元音模式，可留到下一课复习。

### 5. 常见错误

- 将 bell 误拼成 bel。
- 认为两个 l 必须读两次。
- 把 FLSZ 当成没有例外的绝对规则。

例如 bus、yes、if、pal 都说明这个规则并不适用于所有单词。

## Lesson 43 — -all, -oll, -ull

### 1. 学习目标

认识三个常见的特殊拼写模式：

- -all
- -oll
- -ull

它们的元音发音可能与之前学习的普通短元音不同。

### 2. 示例单词

| 模式 | 示例 |
|---|---|
| -all | all, ball, call, fall, tall, wall |
| -oll | roll, toll, poll, scroll |
| -ull | pull, full, bull |

### 3. 发音解释

在常见美式英语中：

- ball 中的 all 通常读 /ɔl/ 或受口音影响的相近读音。
- roll 中的 oll 通常读 /oʊl/。
- pull 中的 ull 通常读 /ʊl/。

这与普通 CVC 短元音规律不同。

例如：

- ball 与 bat 的 a 发音不同。
- roll 与 hot 的 o 发音不同。
- pull 与 sun 的 u 发音不同。

### 4. 与汉语拼音对比

在汉语拼音中，同一个韵母的发音相对稳定。

但英语字母 a 在 cat 和 ball 中的发音可能不同。

这说明英语自然拼读需要学习**常见拼写模式（Spelling Patterns）**，不能只依靠单个字母的基础发音。

### 5. 家庭练习

**分类**

将以下单词分成三组：

ball, pull, roll, call, full, toll, wall, bull

**Word Chain**

`ball → call → fall → tall → wall`

每次改变首音。

### 6. 常见错误

不要将 pull 按短 u /ʌ/ 读成与 dull 押韵。

注意：-oll 和 -ull 并不保证所有单词都使用相同的元音。例如 doll、dull 就有不同的发音。这里学习的是常见词汇模式，而不是绝对规则。

## Lesson 44 — ck /k/

### 1. 学习目标

理解：

**在许多单音节词中，如果短元音后紧接词尾 /k/，通常使用 ck 拼写。**

### 2. 示例单词

| 短元音 | 示例 |
|---|---|
| a | back, pack, sack |
| e | deck, neck, peck |
| i | sick, pick, kick |
| o | rock, sock, lock |
| u | duck, luck, stuck |

### 3. 为什么需要 ck？

比较：

- cat：c 在词首表示 /k/。
- kit：k 在词首表示 /k/。
- duck：ck 在词尾表示 /k/。

三种拼写都可以表示 /k/，但使用位置与拼写模式不同。

### 4. 音素分割

`duck`

- d → /d/
- u → /ʌ/
- ck → /k/

所以 duck 有4个字母、3个音素。

`black`

- b → /b/
- l → /l/
- a → /æ/
- ck → /k/

black 有5个字母、4个音素。

### 5. 家庭练习：Word Chains

**Chain A**

`rock → sock → lock → block`

最后一步增加 /b/，其余步骤替换首音。

**Chain B**

`lick → pick → sick → stick`

最后一步增加 /t/。

### 6. 常见错误

- 把 ck 当成两个独立的 /k/。
- 写成 duk 而不是 duck。
- 认为所有 /k/ 结尾的单词都必须使用 ck。

例如 milk、book、make 就不符合简单的“词尾 /k/ 一律用 ck”的说法。

**家长提醒：** Lesson 44 正是学校之前发给孩子的 UFLI Home Practice 内容，可以直接使用学校的练习纸巩固。

## Lesson 45 — sh /ʃ/

### 1. 学习目标

掌握 `sh` 表示 /ʃ/ 的常见规律。

### 2. 示例单词

| 位置 | 示例 |
|---|---|
| 词首 | ship, shop, shut, shed, shin |
| 词尾 | fish, dish, wish, rash, cash |
| 辅音连缀结合 | shrub, shrink, splash |

### 3. 发音解释

/ʃ/ 是清辅音。

发音时：

1. 舌头靠近上齿龈后方区域。
2. 双唇可略微向前收圆。
3. 气流从舌头与上颚之间通过。
4. 声带通常不振动。

### 4. 与汉语拼音比较

英语 sh 与汉语拼音 sh 不完全相同。

普通话拼音 sh 通常是卷舌擦音，而英语 /ʃ/ 的舌位通常更靠前。

不要直接把 ship 读成拼音 shi 加 p。

### 5. 音素分割

- ship → /ʃ/ /ɪ/ /p/
- shop → /ʃ/ /ɑ/ /p/
- fish → /f/ /ɪ/ /ʃ/
- splash → /s/ /p/ /l/ /æ/ /ʃ/

### 6. 家庭练习

**Word Chain**

`shin → ship → shop → shot`

**另一条**

`rash → dash → dish → wish`

每一步改变一个音素。

### 7. 常见错误

- 将 sh 拆成 /s/ + /h/。
- 用汉语拼音 sh 完全替代英语 /ʃ/。
- 误以为 sh 在任何位置都需要发两次声音。

## Lesson 46 — Voiced th /ð/

### 1. 学习目标

掌握浊音 th /ð/。

常见于：

- this
- that
- them
- then
- these
- those
- the

### 2. 发音方法

1. 舌尖轻轻接触上门牙边缘，或略微伸到上下门牙之间。
2. 让气流通过舌头与牙齿之间的狭窄空间。
3. 声带振动。

可以把手轻轻放在喉咙上，感受发音时的振动。

### 3. 与汉语拼音比较

普通话没有与 /ð/ 完全对应的音素。

中国学习者有时会将 this 读成类似 dis 或 zis。

但 /ð/ 与 /d/、/z/ 都不同。

### 4. 示例对比

| 正确单词 | 常见误读倾向 |
|---|---|
| this | dis |
| that | dat |
| them | dem |
| then | den |

这些右侧拼写仅表示常见替代发音倾向，不是正确读法。

### 5. 家庭练习

**听辨**

- this / dis
- then / den

**短句**

- This is a dog.
- That is my bag.
- They are in the room.

*部分句子包含后续拼读规则，适合家长辅助阅读。*

### 6. 常见错误

不要让孩子把 /ð/ 发成英语 /d/。

也不要过度伸舌或咬住舌头；舌尖轻触即可。

---

## Lesson 47 — Unvoiced th /θ/

### 1. 学习目标

掌握清音 th /θ/，并与 Lesson 46 的 /ð/ 区分。

### 2. 示例单词

| 位置 | 示例 |
|---|---|
| 词首 | thin, thick, thank, think |
| 词尾 | bath, math, path, moth |
| 其他 | three, thumb, cloth |

### 3. 发音方法

/θ/ 与 /ð/ 的舌头位置相近。

主要区别：

- /θ/：声带不振动。
- /ð/：声带振动。

### 4. 两种 th 对比

| 发音 | 类型 | 示例 |
|---|---|---|
| /θ/ | 清辅音 | thin, think, bath |
| /ð/ | 浊辅音 | this, that, them |

### 5. 与汉语拼音比较

普通话没有完全对应的 /θ/。

中国学习者可能将 think 读成类似 sink 或 tink。

这通常是因为把不熟悉的英语音素替换成了已有语言中的近似音。

### 6. 家庭练习

**发音分类**

将以下单词分成两组：

this, thin, that, bath, them, think, then, math

**音素分割**

- thin → /θ/ /ɪ/ /n/
- bath → /b/ /æ/ /θ/
- think → /θ/ /ɪ/ /ŋ/ /k/

### 7. 常见错误

- 把 /θ/ 读成 /s/ 或 /t/。
- 把 /ð/ 和 /θ/ 当成同一个音。
- 认为 th 的发音可以完全根据它在单词中的位置判断。

实际上，th 的发音需要结合词汇和常见模式学习。

## Lesson 48 — ch /tʃ/

### 1. 学习目标

掌握 ch 的常见发音 /tʃ/。

### 2. 示例单词

| 位置 | 示例 |
|---|---|
| 词首 | chin, chat, chop, chip |
| 词尾 | rich, much, such |
| 其他 | lunch, bench, chest |

### 3. 发音解释

/tʃ/ 是一个塞擦音，在英语音系中作为一个音素处理。

虽然发音包含先阻塞再摩擦的过程，但不能简单当作两个独立音素 /t/ + /ʃ/ 来计数。

### 4. 与汉语拼音比较

英语 ch /tʃ/ 与普通话拼音 ch 并不相同。

普通话拼音 ch 通常是送气卷舌塞擦音，而英语 /tʃ/ 的发音位置更靠前。

### 5. 音素分割

- chin → /tʃ/ /ɪ/ /n/
- chat → /tʃ/ /æ/ /t/
- rich → /ɹ/ /ɪ/ /tʃ/
- lunch → /l/ /ʌ/ /n/ /tʃ/

### 6. 家庭练习

**Word Chain**

`chat → chap → chip → chin`

每一步改变一个音素。

**听写**

- chin
- chat
- chop
- rich
- much

### 7. 常见错误

不要把 ch 拆成 /k/ + /h/。

同时注意，以后还会遇到 ch 表示其他声音的单词，例如 school 中的 ch 表示 /k/，chef 中的 ch 表示 /ʃ/。

本课先学习最常见的 /tʃ/。

## Lesson 50 — wh /w/, ph /f/

### 1. 学习目标

学习两个常见字母组合：

- wh → /w/
- ph → /f/

### 2. wh 示例

- when
- what
- which
- whip
- whisk

在多数现代美式英语口音中，wh 与 w 通常都发 /w/。

例如：

- wine
- whine

在许多美国人的发音中，这两个词同音；某些地区或说话者仍保留区别。

### 3. ph 示例

- phone
- photo
- graph
- alphabet
- elephant

其中 ph 通常表示 /f/。

### 4. 与汉语拼音比较

英语 wh 中的 h 通常不单独发音。

ph 也不是 /p/ + /h/，而是共同表示 /f/。

这与汉语拼音中的声母组合并不完全相同。

### 5. 家庭练习

**分类**

将以下单词按 /w/ 和 /f/ 分类：

when, what, whip, phone, photo, graph

**音素分割**

- whip → /w/ /ɪ/ /p/
- phone → /f/ /oʊ/ /n/

注意 phone 包含后续才系统学习的长元音拼写模式，家长可直接示范，不必要求孩子仅凭本课知识独立解码。

### 6. 常见错误

- 将 wh 拆成 /w/ + /h/。
- 将 ph 读成 /p/ + /h/。
- 误以为所有 ph 都必须出现在单词开头。

## Lesson 51 — ng /ŋ/

### 1. 学习目标

学习 ng 常见的鼻音 /ŋ/。

### 2. 示例单词

- sing
- ring
- king
- wing
- long
- song
- bang
- hang

### 3. 发音解释

/ŋ/ 是软腭鼻音。

发音时：

1. 舌头后部接触软腭。
2. 气流主要从鼻腔通过。
3. 声带振动。

在 sing 中：

`s → /s/`

`i → /ɪ/`

`ng → /ŋ/`

因此 sing 有4个字母、3个音素。

### 4. 与汉语拼音比较

普通话拼音中的后鼻韵尾 `-ng`，与英语 /ŋ/ 在发音位置上比较接近。

例如：

- 拼音 ang
- 拼音 ing
- 英语 sing

但普通话拼音的 `-ng` 通常作为韵尾出现，英语 /ŋ/ 则需要放在英语单词的完整语音结构中理解。

### 5. 家庭练习

**听辨**

- sin / sing
- ran / rang

**Word Chain**

`sing → ring → rang → bang → hang`

每一步改变一个音素。

### 6. 常见错误

不要把 sing 末尾的 ng 一律读成 /n/ + /g/ 两个独立音素。

注意：英语中的 ng 在某些单词里确实可能对应 /ŋg/，例如 finger，但 sing 的词尾 ng 通常只表示 /ŋ/。

---

## Lesson 52 — nk /ŋk/

### 1. 学习目标

掌握 nk 的常见发音 /ŋk/。

与 ng 不同，nk 通常包含两个音素：

- /ŋ/
- /k/

### 2. 示例单词

- sink
- pink
- think
- bank
- tank
- thank
- junk
- trunk

### 3. ng 与 nk 对比

| 单词 | 词尾 | 发音 |
|---|---|---|
| sing | ng | /ŋ/ |
| sink | nk | /ŋk/ |
| bang | ng | /ŋ/ |
| bank | nk | /ŋk/ |
| ring | ng | /ŋ/ |
| rink | nk | /ŋk/ |

### 4. 音素数量

**sing**

`/s/ /ɪ/ /ŋ/`

3个音素。

**sink**

`/s/ /ɪ/ /ŋ/ /k/`

4个音素。

**think**

`/θ/ /ɪ/ /ŋ/ /k/`

4个音素。

### 5. 与汉语拼音比较

普通话拼音的后鼻韵尾 `-ng` 可以帮助理解 /ŋ/。

但英语 sink 的末尾还需要额外发出 /k/。

因此：

- sing 末尾是 /ŋ/。
- sink 末尾是 /ŋk/。

### 6. 家庭练习

**听音分类**

- sing
- sink
- bang
- bank
- ring
- rink
- long
- honk

**Word Chain**

`sink → pink → punk → sunk → sun`

其中最后一步删除 /k/，其余步骤每次改变一个音素。

### 7. 常见错误

- 将 sink 的 nk 只读成 /ŋ/。
- 将 sing 的 ng 读成 /ŋg/。
- 误认为 ng 和 nk 都只表示一个音素。

# Part 7. 中国家长常见问题

### Q1：为什么 ship 有4个字母，却只有3个音素？

因为 sh 是两个字母共同表示一个音素 /ʃ/。

### Q2：为什么 think 有5个字母，却只有4个音素？

因为 th 表示一个音素 /θ/，而 nk 表示两个音素 /ŋ/ 和 /k/。

### Q3：为什么 th 有两种发音？

英语中 th 可以表示 /θ/ 或 /ð/。

例如：

- thin：/θ/
- this：/ð/

这两种发音需要通过常见单词和语音练习逐步掌握。

### Q4：为什么 ng 和 nk 不一样？

ng 在 sing 中通常表示一个音素 /ŋ/。

nk 在 sink 中通常表示两个音素 /ŋk/。

### Q5：孩子已经能拼读 ship，还需要练习吗？

可以进一步检查是否真正掌握规律：

- 能否读出 shop、shut、fish？
- 能否拼读以前没见过、但符合已学规则的词？
- 能否听到 /ʃ/ 后写出 sh？
- 能否将 ship 拆成3个音素？

如果都能完成，就可以逐渐增加阅读和写作任务。

### Q6：家长英语发音不标准怎么办？

建议使用学校提供的 UFLI 教学视频、官方练习或可靠的美式英语发音示范。

家长重点负责：

- 组织练习。
- 帮助孩子发现拼写变化。
- 观察孩子是否真正理解规则。
- 鼓励孩子尝试独立拼读。

不需要依靠汉语拼音去猜测英语发音。

# Part 10. 本单元总结

## 三个最重要的学习成果

**1. 理解字母与音素不是一一对应的。**

例如 sh、ch、ck 通常由两个字母共同表示一个音素。

**2. 能区分容易混淆的发音和拼写。**

特别是：

- th /θ/ 与 /ð/
- sh 与 ch
- ng 与 nk
- ck 与 k

**3. 能将拼读规则应用到陌生单词。**

例如孩子学习 sh 后，不只是记住 ship，还能够尝试拼读 shop、shut、fish 等单词。
