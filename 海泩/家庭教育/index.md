# 📚 导语

自己准备给孩子的学习资料，欢迎下载使用，仅限用于家庭学习，请勿商业。欢迎提建议，欢迎共创，欢迎指正错误。

- `数学｜DigitSumPuzzle`系列是通过数学计算，寻找英语句子谜底。有空白模板，也有已经设计好题目的系列可以直接下载打印。如果你下载了母版并设计了题目，也欢迎发给我分享给大家。
- `数学｜MathAdventure`为数学题目探险游戏，单人多人都可以玩，出题比较简单，所以只有空白模板。
- `双语阅读`系列为自制双语阅读材料，三位数编码第一位代表难度级别，如`101别把喵关门外`即难度级别最低的第一篇。
- `梦蝶世界`系列为以我们的生活为原型创作的双语故事，图片由AI生成。
