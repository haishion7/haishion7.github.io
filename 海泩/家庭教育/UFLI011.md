# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Silent Letter？

Silent Letter 指单词拼写中存在，但在该单词的现代标准发音中不单独对应一个声音的字母。

例如：

`knee`

- k：不发音。
- n → /n/
- ee → /i/

所以：

`knee → /ni/`

虽然 knee 有4个字母，但只有2个音素。

再例如：

`write`

- w：不发音。
- r → /r/
- i_e → /aɪ/
- t → /t/

所以：

`write → /raɪt/`

write 有5个字母，但只有3个音素。

### 与汉语拼音比较

汉语拼音主要用于表示普通话的发音，拼写与读音之间的关系相对稳定。

英语则保留了大量历史形成的拼写形式。

例如：

- knee 中的 k 在早期英语中曾经发音。
- write 中的 w 在历史上也曾发音。

随着英语发音变化，这些字母逐渐不再发音，但拼写保留了下来。

因此，英语自然拼读不仅需要学习常见发音规则，也需要认识一些历史拼写模式。

---

## 2.2 Silent Letter 与 Digraph 有什么区别？

这是本单元非常重要的概念。

### Digraph

两个字母共同表示一个音素。

例如：

`sh → /ʃ/`

在 ship 中：

- sh → /ʃ/
- i → /ɪ/
- p → /p/

### Silent Letter

某个字母在特定拼写模式中不单独发音。

例如：

`kn → /n/`

在 knee 中：

- k 不发音。
- n → /n/

### 对比

| 类型 | 拼写 | 发音 | 示例 |
|---|---|---|---|
| Digraph | sh | /ʃ/ | ship |
| Digraph | ch | /tʃ/ | chin |
| Digraph | th | /θ/ 或 /ð/ | thin, this |
| Silent Letter Pattern | kn | /n/ | knee |
| Silent Letter Pattern | wr | /r/ | write |
| Silent Letter Pattern | mb | /m/ | lamb |

在自然拼读教学中，kn、wr、mb 也可以作为整体拼写模式学习。

家长不必要求孩子严格记忆语言学分类，重点是能够正确读出和拼写单词。

---

## 2.3 为什么英语会保留不发音的字母？

主要有几个历史原因。

### 原因一：发音发生变化，拼写没有同步改变

例如：

- knee
- knife
- know

早期英语中的 kn 曾经包含 /k/ 和 /n/ 两个辅音。

现代英语中，词首 k 通常不再发音。

### 原因二：词源和历史拼写被保留

例如：

- write
- wrong
- wrist

这些单词中的 wr 在现代英语中通常读 /r/。

### 原因三：部分字母反映了单词的历史形式或词汇关系

例如：

- lamb
- comb
- thumb

这些单词末尾的 b 通常不发音。

但在某些相关词或不同构词形式中，拼写与发音关系可能发生变化。

例如：

- thumb：/θʌm/
- thimble：/ˈθɪmbəl/

注意：thumb 与 thimble 并不是简单地通过添加一个后缀形成的现代英语规则变化。这里只用于说明相关词的历史拼写和发音可能不同。

---

## 2.4 Silent Letters 与 Silent e 的区别

在 Unit 4 中，我们学习过 Silent e。

例如：

`cap → cape`

末尾 e 虽然不单独发音，但通常会影响前面元音的发音。

而本单元的 kn、wr、mb 不完全一样。

例如：

`knee`

词首 k 不发音，但它并不负责改变 n 的发音。

### 对比

| 模式 | 示例 | 不发音字母的作用 |
|---|---|---|
| VCe | cape | 末尾 e 通常提示长元音 |
| kn | knee | k 不单独发音 |
| wr | write | w 不单独发音 |
| mb | lamb | 词尾 b 不单独发音 |

**家长需要理解：Silent Letter 是一个较宽泛的概念，不同拼写模式中的不发音字母可能具有不同作用。**

# Part 4. 逐项知识点与家庭练习

## Lesson 98A — kn /n/

### 1. 学习目标

掌握词首 `kn` 通常表示 /n/ 的规律。

**核心规律：在许多以 kn 开头的单词中，k 不发音。**

### 2. 示例单词

| 单词 | 发音 | 中文 |
|---|---|---|
| knee | /ni/ | 膝盖 |
| knife | /naɪf/ | 刀 |
| know | /noʊ/ | 知道 |
| knock | /nɑk/ | 敲 |
| knot | /nɑt/ | 结 |
| knit | /nɪt/ | 编织 |
| knob | /nɑb/ | 门把手 |
| knight | /naɪt/ | 骑士 |
| kneel | /nil/ | 跪下 |
| knew | /nu/ | 知道（过去式） |

### 3. 发音解释

例如：

**knee**

`kn → /n/`

`ee → /i/`

因此：

`knee → /ni/`

**knife**

- kn → /n/
- i_e → /aɪ/
- f → /f/

因此：

`knife → /naɪf/`

**knock**

- kn → /n/
- o → /ɑ/
- ck → /k/

因此：

`knock → /nɑk/`

### 4. 与汉语拼音比较

汉语拼音 k 和 n 分别表示不同的声母。

但英语 knee 中的 kn 不应该读成 /k/ + /n/。

不能把 knee 读成类似“克尼”。

正确发音从 /n/ 开始。

### 5. 同音词（Homophones）

英语中有些单词虽然拼写不同，但发音相同。

例如：

| 单词 A | 单词 B | 发音 |
|---|---|---|
| know | no | /noʊ/ |
| knight | night | /naɪt/ |
| knew | new | /nu/（常见美式英语） |
| knot | not | /nɑt/（常见美式英语） |

这说明：

**听到一个单词的发音，并不一定能够唯一确定它的拼写。**

### 6. 家庭练习

**音素分割**

- knee → /n/ /i/
- know → /n/ /oʊ/
- knock → /n/ /ɑ/ /k/
- knife → /n/ /aɪ/ /f/

**分类**

将以下单词分成 kn 和普通 n 开头两组：

knee, name, know, nest, knife, night, knock, nose

**同音词配对**

- know — no
- knight — night
- knew — new
- knot — not

**听写**

- knee
- knife
- know
- knock
- knot

### 7. 家长常见错误

- 将 kn 读成 /k/ + /n/。
- 认为 k 在所有单词中都不发音。
- 将 know 与 no 混淆。
- 将 knight 与 night 混淆。

## Lesson 98B — wr /r/

### 1. 学习目标

掌握词首 `wr` 通常表示 /r/ 的规律。

**核心规律：在许多以 wr 开头的单词中，w 不发音。**

### 2. 示例单词

| 单词 | 发音 | 中文 |
|---|---|---|
| write | /raɪt/ | 写 |
| wrong | /rɔŋ/ 或 /rɑŋ/ | 错误的 |
| wrist | /rɪst/ | 手腕 |
| wrap | /ræp/ | 包裹 |
| wreck | /rɛk/ | 失事；破坏 |
| wrinkle | /ˈrɪŋkəl/ | 皱纹 |
| writer | /ˈraɪtɚ/ | 作者 |
| wrote | /roʊt/ | 写（过去式） |
| written | /ˈrɪtən/ | 写过的 |
| wrench | /rɛntʃ/ | 扳手 |

### 3. 发音解释

例如：

**write**

- w：不发音。
- r → /r/
- i_e → /aɪ/
- t → /t/

因此：

`write → /raɪt/`

**wrap**

- w：不发音。
- r → /r/
- a → /æ/
- p → /p/

因此：

`wrap → /ræp/`

### 4. 与汉语拼音比较

英语 r 的发音与汉语拼音 r 不完全相同。

例如：

- write
- red
- run

这些单词中的 r 通常使用美式英语 /ɹ/。

家长不要把 write 读成 w 加汉语拼音 r。

### 5. 同音词

| 单词 A | 单词 B | 发音 |
|---|---|---|
| write | right | /raɪt/ |
| write | rite | /raɪt/ |
| wrap | rap | /ræp/ |
| wreck | reck | /rɛk/ |

其中 reck 是较少见的词，不需要孩子重点记忆。

### 6. 家庭练习

**音素分割**

- write → /r/ /aɪ/ /t/
- wrap → /r/ /æ/ /p/
- wrist → /r/ /ɪ/ /s/ /t/
- wrong → /r/ /ɔ/ /ŋ/（发音随口音变化）

**分类**

将以下单词分成 wr 和普通 r 开头两组：

write, red, wrong, run, wrist, rabbit, wrap, road

**同音词配对**

- write — right
- wrap — rap

**听写**

- write
- wrong
- wrist
- wrap
- wrote

### 7. 家长常见错误

- 将 wr 读成 /w/ + /r/。
- 把 write 读成两个音节。
- 将 write 与 right 混淆。
- 认为所有 w 都不发音。

## Lesson 98C — mb /m/

### 1. 学习目标

掌握词尾 `mb` 通常表示 /m/ 的规律。

**核心规律：在许多以 mb 结尾的单词中，b 不发音。**

### 2. 示例单词

| 单词 | 发音 | 中文 |
|---|---|---|
| lamb | /læm/ | 小羊 |
| comb | /koʊm/ | 梳子 |
| thumb | /θʌm/ | 拇指 |
| climb | /klaɪm/ | 攀爬 |
| bomb | /bɑm/ | 炸弹 |
| crumb | /krʌm/ | 面包屑 |
| dumb | /dʌm/ | 哑的；愚蠢的 |
| numb | /nʌm/ | 麻木的 |
| limb | /lɪm/ | 肢体 |
| tomb | /tum/ | 坟墓 |

### 3. 发音解释

例如：

**lamb**

- l → /l/
- a → /æ/
- m → /m/
- b：不发音。

因此：

`lamb → /læm/`

**comb**

- c → /k/
- o → /oʊ/
- m → /m/
- b：不发音。

因此：

`comb → /koʊm/`

**thumb**

- th → /θ/
- u → /ʌ/
- m → /m/
- b：不发音。

因此：

`thumb → /θʌm/`

### 4. 与汉语拼音比较

汉语拼音中的 m 和 b 分别表示不同的辅音。

但英语 lamb 中的 mb 不能读成 /m/ + /b/。

词尾 b 通常不发音。

### 5. 为什么有些 mb 单词的 b 会发音？

需要注意：

**并不是所有包含 mb 的单词都遵循词尾 b 不发音的规律。**

例如：

- number → /ˈnʌmbɚ/
- timber → /ˈtɪmbɚ/
- member → /ˈmɛmbɚ/

这些单词中的 b 通常发音。

因此，本课的规律主要针对词尾 `-mb`。

### 6. 家庭练习

**音素分割**

- lamb → /l/ /æ/ /m/
- comb → /k/ /oʊ/ /m/
- thumb → /θ/ /ʌ/ /m/
- climb → /k/ /l/ /aɪ/ /m/

**分类**

将以下单词分成 b 发音和 b 不发音两组：

lamb, number, comb, timber, thumb, member, climb, bomb

**听写**

- lamb
- comb
- thumb
- climb
- crumb

### 7. 家长常见错误

- 将 lamb 末尾的 b 读出来。
- 将 comb 读成两个音节。
- 认为所有 mb 中的 b 都不发音。
- 将 thumb 中的 th 误读成 /t/ 或 /s/。

# Part 6. UFLI 教学方法与家庭练习

## 6.1 八个教学环节

| UFLI 环节 | 学习目标 | 家庭练习 |
|---|---|---|
| Phonemic Awareness | 听辨实际音素 | knee → /n/ /i/ |
| Visual Drill | 看拼写说发音 | kn、wr、mb |
| Auditory Drill | 听音选择拼写 | 结合完整单词判断 n/kn |
| Blending Drill | 合成声音 | /r/ /aɪ/ /t/ → write |
| New Concept | 学习不发音字母 | 解释 kn、wr、mb |
| Word Work | 拼读与拼写 | 使用字母卡片构词 |
| Irregular Words | 特殊高频词 | 复习学校当周 Heart Words |
| Connected Text | 阅读应用 | 阅读包含目标词的句子和短文 |

### Auditory Drill 特别提醒

听到 /ni/ 时，孩子无法仅凭声音确定应该写 knee 还是其他拼写。

因此，听写 Silent Letter 单词时，应结合：

- 单词意义。
- 上下文。
- 已学拼写模式。
- 具体词汇记忆。

例如：

“Write the word knee, the part of your leg.”

这样可以避免同音词带来的歧义。

## 6.2 每天15分钟家庭练习

### Step 1：听音与音素分割（3分钟）

家长读：

- knee
- write
- lamb

孩子分别说出音素。

### Step 2：拼写模式卡片（3分钟）

展示：

- kn
- wr
- mb

孩子说出实际发音，并指出哪个字母不发音。

### Step 3：Word Work（5分钟）

准备字母卡片：

- k、n、e、e
- w、r、i、t、e
- l、a、m、b

让孩子排列成：

- knee
- write
- lamb

然后读出单词，并指出不发音的字母。

### Step 4：句子阅读（4分钟）

- I know the answer.
- I can write my name.
- The lamb is on the farm.
- My thumb hurts.
- Please knock on the door.

这些句子包含部分其他拼写模式或高频词，可以由家长辅助阅读。

# Part 7. 阅读与写作练习

## 7.1 阅读短文：The Little Lamb

**The Little Lamb**

A little lamb was on the farm.

The lamb saw a boy.

The boy had a comb.

He wanted to help the lamb.

He used the comb to brush its wool.

The lamb was happy.

The boy smiled.

> 本文用于家庭阅读理解练习，并非严格限定 Lessons 1–98 已学规则的官方 Decodable Text。wanted、used、brush、wool 等词可能需要家长辅助。

### 阅读理解问题

1. Where was the lamb?
2. What did the boy have?
3. What did the boy use the comb for?
4. Why do you think the boy wanted to help the lamb?
5. How do you think the lamb felt?
6. Can you retell the story in your own words?

前3个问题主要考察事实理解，第4、5个问题引导推理，第6个问题练习故事复述。

## 7.2 写作练习

### Level 1：听写单词

- knee
- know
- write
- lamb
- thumb

### Level 2：完成句子

1. I can ______ my name.
2. My ______ hurts.
3. The ______ is on the farm.
4. I ______ the answer.
5. Please ______ on the door.

### Level 3：自主造句

从简单句开始：

`I see a lamb.`

增加细节：

`I see a little lamb.`

增加地点：

`I see a little lamb on the farm.`

`I see a little lamb running on the farm.`

### 与中文写作比较

中国小学看图写话常常鼓励孩子写清楚：

- 谁？
- 在哪里？
- 做什么？
- 为什么？

英语写作也可以使用类似方法逐步扩展。

家长可以问：

- Who is in the picture?
- Where is the lamb?
- What is the lamb doing?
- Why is the lamb running?

建议优先鼓励孩子完整表达，再选择少量目标词进行拼写纠正。

# Part 8. 中国家长常见问题

### Q1：为什么 knee 中的 k 不发音？

因为英语保留了历史拼写。在现代英语中，词首 kn 通常读 /n/。

### Q2：为什么 write 中的 w 不发音？

因为现代英语中词首 wr 通常读 /r/，w 不再单独发音。

### Q3：为什么 lamb 中的 b 不发音？

因为在许多以 -mb 结尾的单词中，b 通常不发音。

### Q4：是不是所有 kn、wr、mb 都有不发音字母？

不是所有位置都适用相同规则。

例如：

- knee：词首 kn，k 不发音。
- write：词首 wr，w 不发音。
- lamb：词尾 mb，b 不发音。
- number：mb 位于词中，b 通常发音。

### Q5：Silent Letters 和 Silent e 是一样的吗？

不完全一样。

Silent e 在 VCe 模式中通常会影响前面元音的发音。

而 kn、wr、mb 中的不发音字母主要体现历史拼写模式。

### Q6：为什么 know 和 no 发音相同？

因为 know 中的 k 不发音。

它们是同音词（Homophones），需要通过拼写和上下文区分。

### Q7：孩子需要记住所有 Silent Letter 单词吗？

不需要一次全部记住。

建议：

1. 先掌握 kn、wr、mb 三种常见模式。
2. 学习少量高频示例词。
3. 通过阅读积累词汇。
4. 通过听写巩固准确拼写。
5. 结合词义区分同音词。

# Part 11. 本单元总结

## 三个最重要的学习成果

**1. 理解英语单词中可能存在不发音的字母。**

例如：

- knee：k 不发音。
- write：w 不发音。
- lamb：b 不发音。

**2. 掌握常见 Silent Letter 拼写模式。**

例如：

- kn → /n/
- wr → /r/
- mb → /m/

**3. 理解发音相同的单词可能具有不同拼写和意义。**

例如：

- know / no
- write / right
- knight / night

孩子需要通过拼写规律、词义和上下文来区分这些词。
