# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Morphological Awareness（词素意识）？

Morphological Awareness 指识别和理解单词中有意义的组成部分的能力。

例如：

`unhappiness`

可以拆成：

`un- + happy + -ness`

其中：

- happy：快乐的。
- un-：表示否定。
- -ness：将形容词转变为表示状态或性质的名词。

因此：

`unhappiness = 不快乐的状态`

### 与 Phonics 的区别

**Phonics：** 关注字母与声音的对应关系。

例如：

`ship → sh + i + p`

**Morphology：** 关注单词的意义结构。

例如：

`helpful → help + ful`

两种能力可以相互配合。

例如：

`unhelpful`

孩子既可以通过自然拼读读出单词，也可以通过词素理解意义。

---

## 2.2 Base Word 与 Root 有什么区别？

这两个概念在日常教学中有时会被混用，但严格来说并不完全相同。

### Base Word（基础词）

可以作为添加词缀基础的词。

例如：

`help → helpful`

help 本身就是一个完整单词。

### Root（词根）

承载核心意义的组成部分，不一定能独立成为英语单词。

例如：

`spect`

来自表示“看”的拉丁语词根。

相关单词包括：

- inspect
- respect
- spectator

spect 本身通常不能作为现代英语中的独立普通单词使用。

### 与中文构词比较

中文可以通过组合具有意义的汉字形成词语。

例如：

- 学
- 学习
- 学生
- 学校

英语也可以通过词根和词缀构词。

但需要注意，**英语词根不一定是一个可以独立使用的单词**。

对于小学阶段的孩子，建议先学习容易理解的基础词与词缀，再逐步接触拉丁语、希腊语词根。

---

## 2.3 什么是 Derivational Affix（派生词缀）？

派生词缀可以改变单词的意义，有时也会改变词性。

例如：

`happy → happiness`

- happy：形容词。
- happiness：名词。

`teach → teacher`

- teach：动词。
- teacher：名词。

`comfort → comfortable`

- comfort：名词或动词。
- comfortable：形容词。

### 与中文比较

中文也可以通过添加有意义的成分形成新词。

例如：

- 教 → 教师
- 工作 → 工作者
- 快乐 → 快乐感

英语则经常通过特定后缀表达这些变化。

例如：

- teach → teacher
- work → worker
- happy → happiness

---

## 2.4 为什么词缀学习能帮助阅读？

假设孩子第一次看到：

`disagreement`

可以尝试拆分：

`dis- + agree + -ment`

其中：

- dis-：表示否定或相反。
- agree：同意。
- -ment：形成名词。

因此 disagreement 表示“不同意；分歧”。

孩子不需要把每个较长的单词都当作完全陌生的整体来记忆。

### 家长需要理解

词素分析可以帮助孩子：

1. 识别熟悉的组成部分。
2. 推测单词意义。
3. 理解词性变化。
4. 改进拼写。
5. 扩展词汇量。

但并非所有单词都能通过简单拆分准确推测意义。

# Part 4. 逐课知识点与家庭练习

## Lesson 119 — Suffixes -sion、-tion

### 1. 学习目标

学习 `-sion` 和 `-tion` 的常见发音及构词作用。

### 2. 示例单词

**-tion**

| 单词 | 中文 |
|---|---|
| action | 行动 |
| station | 车站 |
| nation | 国家 |
| motion | 运动 |
| direction | 方向 |
| invention | 发明 |
| education | 教育 |
| information | 信息 |

**-sion**

| 单词 | 中文 |
|---|---|
| vision | 视觉；愿景 |
| decision | 决定 |
| television | 电视 |
| explosion | 爆炸 |
| confusion | 困惑 |
| permission | 许可 |
| discussion | 讨论 |

### 3. 发音解释

`-tion` 通常发 /ʃən/。

例如：

`action → /ˈækʃən/`

`station → /ˈsteɪʃən/`

`-sion` 可以有不同发音。

例如：

- vision：/ˈvɪʒən/
- decision：/dɪˈsɪʒən/
- discussion：/dɪˈskʌʃən/

因此，不能认为 -sion 永远只有一种发音。

### 4. 与汉语拼音比较

英语 /ʃ/ 和 /ʒ/ 与汉语拼音 sh、r 等声音并不完全相同。

另外，-tion 中的字母并不是逐个发音。

例如 action 不应读成 act-i-on 三个独立部分。

### 5. 构词与词义

例如：

`act → action`

- act：行动。
- action：行动；行为。

`invent → invention`

- invent：发明。
- invention：发明物；发明行为。

### 6. 家庭练习

**分类**

action, vision, station, decision, motion, discussion

按照 -tion、-sion 分类。

**音节划分**

- action → ac-tion
- station → sta-tion
- decision → de-ci-sion
- invention → in-ven-tion

**听写**

- action
- station
- motion
- vision
- decision

### 7. 家长常见错误

- 将 -tion 逐字母发音。
- 认为 -sion 永远发 /ʒən/。
- 认为所有以 -tion 结尾的词都能通过简单删除 -tion 得到一个基础词。

## Lesson 120 — Suffix -ture

### 1. 学习目标

认识 `-ture` 的常见发音及其在单词中的使用。

### 2. 示例单词

| 单词 | 中文 |
|---|---|
| picture | 图片 |
| nature | 自然 |
| future | 未来 |
| capture | 捕获 |
| mixture | 混合物 |
| adventure | 冒险 |
| creature | 生物 |
| furniture | 家具 |
| temperature | 温度 |

### 3. 发音解释

在许多常见美式英语单词中，-ture 发 /tʃɚ/。

例如：

`picture → /ˈpɪktʃɚ/`

`nature → /ˈneɪtʃɚ/`

`future → /ˈfjutʃɚ/`

### 4. 为什么 -ture 不按普通 VCe 规则发音？

因为 -ture 是一种需要整体学习的词尾模式。

例如 picture 不能简单按照 pic-tu-re 三个部分逐字母拼读。

### 5. 与中文比较

中文中，“图画”“自然”“未来”等词通常通过汉字组合表示意义。

英语中的 picture、nature、future 则包含具有历史来源的拼写模式。

并不是所有包含 -ture 的单词都能简单拆分为现代英语基础词加后缀。

### 6. 家庭练习

**音节划分**

- picture → pic-ture
- nature → na-ture
- future → fu-ture
- capture → cap-ture

**分类阅读**

picture, nature, future, capture, mixture

让孩子找出共同的 -ture。

**听写**

- picture
- nature
- future
- capture

### 7. 家长常见错误

- 将 -ture 读成 /t/ + /u/ + /r/ + /e/。
- 认为所有 -ture 单词都有完全相同的重音。
- 认为 -ture 在每个单词中都一定是可以独立分析的派生后缀。

## Lesson 121 — Suffixes -er、-or、-ist

### 1. 学习目标

学习表示人物、职业、身份或从事某种活动的常见后缀。

### 2. -er 示例

| 基础词 | 新单词 | 中文 |
|---|---|---|
| teach | teacher | 教师 |
| work | worker | 工作者 |
| paint | painter | 画家；油漆工 |
| farm | farmer | 农民 |
| sing | singer | 歌手 |
| drive | driver | 司机 |

### 3. -or 示例

| 单词 | 中文 |
|---|---|
| actor | 演员 |
| inventor | 发明家 |
| director | 导演；主管 |
| visitor | 访客 |
| editor | 编辑 |
| conductor | 指挥；售票员 |

### 4. -ist 示例

| 单词 | 中文 |
|---|---|
| artist | 艺术家 |
| scientist | 科学家 |
| pianist | 钢琴家 |
| dentist | 牙医 |
| cyclist | 骑自行车的人 |
| violinist | 小提琴演奏者 |

### 5. 与中文比较

中文常通过“者”“家”“员”“师”等表示职业或身份。

例如：

- 教 → 教师
- 科学 → 科学家
- 艺术 → 艺术家

英语则可以通过 -er、-or、-ist 等构词。

### 6. 家长需要注意

不是所有 -er 都表示人物。

例如：

- taller：比较级。
- teacher：教师。

两者虽然都包含 -er，但功能不同。

### 7. 家庭练习

**分类**

teacher, actor, artist, farmer, inventor, scientist

按照 -er、-or、-ist 分类。

**词义推测**

- teach → teacher
- invent → inventor
- art → artist

**听写**

- teacher
- farmer
- actor
- artist
- scientist

### 8. 家长常见错误

- 认为 -er 永远表示人物。
- 认为所有职业名称都可以直接通过添加 -er 构成。
- 将 -or、-er、-ist 随意替换。

## Lesson 122 — Suffix -ish

### 1. 学习目标

学习 -ish 的常见意义，包括“具有某种性质”“有点像”“大约”等。

### 2. 示例单词

| 基础词 | 新单词 | 中文 |
|---|---|---|
| child | childish | 孩子气的 |
| fool | foolish | 愚蠢的 |
| self | selfish | 自私的 |
| green | greenish | 带点绿色的 |
| red | reddish | 微红的 |
| small | smallish | 有点小的 |

### 3. 意义解释

**green → greenish**

绿色 → 带点绿色的。

**child → childish**

孩子 → 孩子气的。

但 childish 在某些语境中具有负面含义，不只是“像孩子一样”。

### 4. 与中文比较

中文可以使用：

- 有点……
- ……似的
- 略带……

例如：

- greenish：有点绿的。
- reddish：微红的。

### 5. 拼写变化

例如：

`red + ish → reddish`

这里双写 d。

但：

`green + ish → greenish`

直接添加后缀。

### 6. 家庭练习

**词义配对**

- greenish → a little green
- reddish → a little red
- childish → behaving like a child

**听写**

- childish
- foolish
- selfish
- greenish
- reddish

### 7. 家长常见错误

- 认为 -ish 永远表示“有点”。
- 认为所有 -ish 单词都具有负面意义。
- 忽略部分单词添加 -ish 时的拼写变化。

## Lesson 123 — Suffix -y

### 1. 学习目标

学习 -y 表示“具有某种性质”“充满某种事物”等常见意义。

### 2. 示例单词

| 基础词 | 新单词 | 中文 |
|---|---|---|
| rain | rainy | 下雨的 |
| sun | sunny | 阳光充足的 |
| cloud | cloudy | 多云的 |
| wind | windy | 有风的 |
| snow | snowy | 下雪的 |
| dirt | dirty | 脏的 |
| luck | lucky | 幸运的 |
| mess | messy | 凌乱的 |

### 3. 意义解释

例如：

`rain → rainy`

雨 → 下雨的。

`cloud → cloudy`

云 → 多云的。

### 4. 与中文比较

中文可以通过“有……的”“……的”表达类似意义。

例如：

- wind → windy：风 → 有风的。
- cloud → cloudy：云 → 多云的。

### 5. 拼写变化

有些词直接加 -y：

`rain + y → rainy`

有些词需要双写末尾辅音：

`sun + y → sunny`

还有些词存在其他拼写变化。

### 6. 家庭练习

**天气词汇分类**

rainy, sunny, cloudy, windy, snowy

让孩子描述当天的天气。

**句子**

- It is sunny today.
- It is windy outside.
- The sky is cloudy.

**听写**

- rainy
- sunny
- cloudy
- windy
- snowy

### 7. 家长常见错误

- 认为所有 -y 单词都是形容词。
- 认为所有基础词添加 -y 都不需要拼写变化。
- 忽略 -y 在不同单词中的其他功能。

## Lesson 124 — Suffix -ness

### 1. 学习目标

学习 -ness 将部分形容词转变为表示状态或性质的名词。

### 2. 示例单词

| 形容词 | 名词 | 中文 |
|---|---|---|
| happy | happiness | 快乐 |
| sad | sadness | 悲伤 |
| kind | kindness | 善良 |
| dark | darkness | 黑暗 |
| weak | weakness | 虚弱 |
| fair | fairness | 公平 |
| sick | sickness | 疾病；生病状态 |

### 3. 词性变化

例如：

**happy**

形容词：快乐的。

**happiness**

名词：快乐。

句子对比：

- She is happy.
- Her happiness is important.

### 4. 与中文比较

中文：

- 快乐的
- 快乐

英语：

- happy
- happiness

英语常通过后缀改变词性，而中文可能不需要改变词形。

### 5. 拼写变化

例如：

`happy + ness → happiness`

需要将 y 改为 i。

但：

`kind + ness → kindness`

直接添加。

### 6. 家庭练习

**词形转换**

- happy → happiness
- sad → sadness
- kind → kindness
- dark → darkness

**听写**

- happiness
- sadness
- kindness
- darkness

### 7. 家长常见错误

- 写成 happyness。
- 认为所有形容词都可以直接加 -ness。
- 忽略词性变化。

## Lesson 125 — Suffix -ment

### 1. 学习目标

学习 -ment 的常见名词构词功能。

### 2. 示例单词

| 基础词 | 新单词 | 中文 |
|---|---|---|
| enjoy | enjoyment | 享受；乐趣 |
| agree | agreement | 协议；同意 |
| move | movement | 运动 |
| improve | improvement | 改进 |
| develop | development | 发展 |
| excite | excitement | 兴奋 |
| pay | payment | 付款 |

### 3. 意义解释

例如：

`improve → improvement`

改进（动词）→ 改进、改善（名词）。

`agree → agreement`

同意（动词）→ 同意、协议（名词）。

### 4. 与中文比较

中文可以通过“改进”“发展”等词在不同语境中承担不同语法功能。

英语则经常通过 -ment 形成名词。

### 5. 拼写变化

注意：

`move + ment → movement`

保留 e。

`agree + ment → agreement`

也保留 e。

因此，不能把 Unit 12 的 Drop-e Rule 应用于所有后缀。

### 6. 家庭练习

**词形转换**

- enjoy → enjoyment
- agree → agreement
- move → movement
- improve → improvement

**听写**

- enjoyment
- agreement
- movement
- improvement

### 7. 家长常见错误

- 认为添加 -ment 必须删除词尾 e。
- 认为所有动词都可以直接加 -ment。
- 忽略派生词可能具有比基础词更具体的意义。

## Lesson 126 — Suffixes -able、-ible

### 1. 学习目标

学习 -able、-ible 表示“能够……的”“适合……的”等常见意义。

### 2. -able 示例

| 基础词 | 新单词 | 中文 |
|---|---|---|
| read | readable | 可读的 |
| wash | washable | 可洗的 |
| enjoy | enjoyable | 令人愉快的 |
| comfort | comfortable | 舒适的 |
| predict | predictable | 可预测的 |
| break | breakable | 易碎的 |

### 3. -ible 示例

| 单词 | 中文 |
|---|---|
| possible | 可能的 |
| visible | 可见的 |
| flexible | 灵活的 |
| terrible | 糟糕的 |
| responsible | 负责任的 |
| sensible | 明智的 |

### 4. -able 与 -ible 的区别

两者都可以形成形容词，但拼写选择不能只根据发音确定。

一般来说：

- -able 常与可以独立使用的基础词结合。
- -ible 常出现在某些拉丁语来源的词中。

但这只是常见倾向，不是绝对规则。

### 5. 与中文比较

中文可以使用：

- 可……
- 能够……
- 适合……

例如：

- readable：可读的。
- washable：可洗的。
- predictable：可预测的。

### 6. 发音说明

-able 和 -ible 通常包含弱读元音。

例如：

- readable：/ˈridəbəl/
- possible：/ˈpɑsəbəl/

孩子需要注意非重读音节中的 /ə/。

### 7. 家庭练习

**分类**

readable, possible, washable, visible, enjoyable, flexible

按照 -able、-ible 分类。

**词义推测**

- read + able → readable
- wash + able → washable
- predict + able → predictable

**听写**

- readable
- washable
- possible
- visible
- comfortable

### 8. 家长常见错误

- 认为 -able 与 -ible 可以随意替换。
- 认为所有 -able、-ible 单词都能通过简单拆分推测准确意义。
- 忽略弱读元音。

## Lesson 127 — Prefixes uni-、bi-、tri-

### 1. 学习目标

学习表示数量的常见前缀：

- uni-：一。
- bi-：二。
- tri-：三。

### 2. uni- 示例

| 单词 | 中文 |
|---|---|
| unicycle | 独轮车 |
| unicorn | 独角兽 |
| uniform | 制服 |
| unilateral | 单方面的 |
| unison | 齐声；一致 |

其中部分单词的现代意义不能仅通过 uni- 机械推断。

### 3. bi- 示例

| 单词 | 中文 |
|---|---|
| bicycle | 自行车 |
| bilingual | 双语的 |
| binoculars | 双筒望远镜 |
| bimonthly | 每两个月一次或每月两次 |
| bilateral | 双边的 |

### 4. tri- 示例

| 单词 | 中文 |
|---|---|
| tricycle | 三轮车 |
| triangle | 三角形 |
| tripod | 三脚架 |
| trilogy | 三部曲 |
| trilingual | 使用三种语言的 |

### 5. 与中文比较

中文可以使用“一、二、三”“单、双、三”等构词。

例如：

- 独轮车
- 自行车
- 三轮车

英语：

- unicycle
- bicycle
- tricycle

其中 cycle 与轮子、循环等概念有关。

### 6. 家庭练习

**词义配对**

- unicycle → one wheel
- bicycle → two wheels
- tricycle → three wheels

**分类**

unicycle, bicycle, tricycle, bilingual, triangle, unicorn

按照 uni-、bi-、tri- 分类。

**听写**

- unicycle
- bicycle
- tricycle
- triangle
- bilingual

### 7. 家长常见错误

- 认为所有 uni、bi、tri 开头的单词都可以简单按数字前缀拆分。
- 认为 bimonthly 只有一种明确含义。
- 忽略词根与前缀结合后的实际词义。

# Part 7. 中国家长常见问题

### Q1：为什么 action 中的 -tion 不逐字母发音？

因为 -tion 是英语中的常见词尾拼写模式，通常发 /ʃən/。

### Q2：为什么 vision 和 discussion 中的 -sion 发音不同？

因为 -sion 可以表示 /ʒən/ 或 /ʃən/，需要结合具体单词学习。

### Q3：为什么 teacher 和 taller 都有 -er，但意思不同？

因为 -er 可以具有不同功能。

- teacher：表示从事教学的人。
- taller：表示比较级。

### Q4：为什么 happiness 要把 y 改成 i？

因为 happy 以辅音字母加 y 结尾，添加 -ness 时通常将 y 改为 i。

### Q5：为什么 movement 不删除 e？

因为添加 -ment 时通常保留基础词末尾的 e。

Drop-e Rule 主要适用于特定后缀，不能机械应用到所有后缀。

### Q6：为什么 readable 和 possible 的结尾不同？

因为 -able 和 -ible 是两种相关但不同的拼写形式。

准确选择需要结合词汇、词源和常见构词规律。

### Q7：孩子需要学习拉丁语和希腊语吗？

不需要先系统学习古典语言。

小学阶段可以先理解常见词根和词缀的意义，例如：

- uni-：一
- bi-：二
- tri-：三

以后阅读学术词汇时，再逐步扩展词源知识。

### Q8：学完 UFLI 128个 Lesson，是否就掌握英语阅读了？

不是。

完成 UFLI Foundations 的全部课程，意味着孩子已经系统接触了大量基础英语拼读和构词规律。

但成熟的阅读能力还包括：

- 阅读流利度（Reading Fluency）。
- 词汇理解（Vocabulary）。
- 语法与句法理解（Syntax）。
- 文章理解（Reading Comprehension）。
- 背景知识（Background Knowledge）。
- 推理与批判性思考（Inference and Critical Thinking）。
- 写作表达（Writing）。

因此，Phonics 是阅读能力的重要基础，但不是阅读学习的终点。
