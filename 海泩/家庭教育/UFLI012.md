# Part 2. 中国家长需要理解的基础概念

## 2.1 什么是 Morpheme（词素）？

Morpheme 是语言中具有意义或语法功能的最小单位。

例如：

`unhappy`

可以拆成：

`un- + happy`

其中：

- happy：快乐的。
- un-：表示否定。
- unhappy：不快乐的。

再例如：

`jumped`

可以拆成：

`jump + -ed`

其中：

- jump：跳。
- -ed：在这里表示规则动词的过去式形式。

### 与 Phoneme 的区别

| 概念 | 中文 | 作用 | 示例 |
|---|---|---|---|
| Phoneme | 音素 | 区分发音和词义 | /k/、/æ/、/t/ |
| Grapheme | 字素 | 用字母表示声音 | c、a、t、sh |
| Morpheme | 词素 | 表示意义或语法功能 | un-、happy、-ed |
| Syllable | 音节 | 语音节奏单位 | hap-py |

**注意：词素、音素、音节并不是同一个概念。**

例如：

`unhappy`

- 词素：un- + happy，共2个。
- 音节：un-hap-py，共3个。

---

## 2.2 与中文构词的比较

中文也可以通过组合有意义的成分形成词语。

例如：

- 快乐
- 不快乐
- 重新开始
- 读者
- 工作人员

英语同样可以通过词缀改变意义：

| 英语 | 中文 | 构词 |
|---|---|---|
| happy | 快乐的 | 基础词 |
| unhappy | 不快乐的 | un- + happy |
| read | 阅读 | 基础词 |
| reread | 重新阅读 | re- + read |
| help | 帮助 | 基础词 |
| helpful | 有帮助的 | help + -ful |
| careless | 粗心的 | care + -less |

### 两种语言的重要区别

中文通常不需要通过改变汉字本身的拼写来表示语法变化。

例如：

- 我跳。
- 我昨天跳了。
- 我正在跳。

英语则经常通过词尾或助动词表达相应的语法关系：

- I jump.
- I jumped yesterday.
- I am jumping.

不过，英语 -ed、-ing 并不分别等同于中文“了”“正在”，需要结合句子结构理解。

---

## 2.3 Prefix 与 Suffix 有什么区别？

**Prefix（前缀）**：加在基础词前面。

例如：

`un- + kind → unkind`

**Suffix（后缀）**：加在基础词后面。

例如：

`kind + -ness → kindness`

| 类型 | 位置 | 示例 |
|---|---|---|
| Prefix | 词前 | unhappy, rewrite |
| Suffix | 词后 | helpful, slowly |
| Prefix + Suffix | 词前与词后 | unhelpful |

### 为什么学习词缀很重要？

因为孩子遇到一个不熟悉的单词时，可以尝试拆分它。

例如：

`unhelpful`

拆成：

`un- + help + -ful`

即使孩子第一次看到这个词，也可以根据已学词素推测：

- help：帮助。
- -ful：具有某种性质。
- un-：否定。

因此 unhelpful 表示“没有帮助的”。

# Part 4. 逐课知识点与家庭练习

## Lesson 99 — Suffixes -s、-es

### 1. 学习目标

复习并扩展 -s、-es 的常见用途，包括名词复数和动词形式。

### 2. 名词复数

| 单数 | 复数 | 中文 |
|---|---|---|
| cat | cats | 猫 |
| dog | dogs | 狗 |
| book | books | 书 |
| box | boxes | 盒子 |
| dish | dishes | 盘子 |
| bus | buses | 公共汽车 |
| wish | wishes | 愿望 |

### 3. 三种常见发音

| 词尾发音 | 示例 |
|---|---|
| /s/ | cats, books, cups |
| /z/ | dogs, pens, bags |
| /ɪz/ | boxes, dishes, buses |

**关键：判断发音时，要关注基础词最后的音素，而不是只看最后一个字母。**

### 4. 动词中的 -s、-es

例如：

- I run.
- He runs.
- I watch.
- She watches.

这里 -s、-es 不表示复数，而是与一般现在时第三人称单数有关。

### 5. 与中文比较

中文：

- 一只猫
- 两只猫

英语：

- one cat
- two cats

中文名词通常不因数量变化而改变字形，但英语名词常需要复数形式。

### 6. 家庭练习

**分类**

cats, dogs, boxes, books, dishes, pens

按照 /s/、/z/、/ɪz/ 分类。

**听写**

- cats
- dogs
- boxes
- dishes
- wishes

**句子**

- I have two cats.
- She watches the birds.
- He runs fast.

### 7. 家长常见错误

- 认为 -s 永远读 /s/。
- 认为 -es 永远增加一个音节。
- 将名词复数与动词第三人称单数混为一谈。

## Lesson 100 — Suffixes -er、-est

### 1. 学习目标

学习 -er、-est 表示比较的常见情况。

### 2. 示例单词

| 原级 | 比较级 | 最高级 |
|---|---|---|
| tall | taller | tallest |
| small | smaller | smallest |
| fast | faster | fastest |
| long | longer | longest |
| short | shorter | shortest |
| cold | colder | coldest |

### 3. 意义解释

**tall**

高的。

**taller**

更高的。

**tallest**

最高的。

例如：

- Tom is tall.
- Ben is taller than Tom.
- Sam is the tallest.

### 4. 与中文比较

中文：

- 高
- 更高
- 最高

英语：

- tall
- taller
- tallest

中文通常使用“更”“最”等独立成分，英语则可以通过添加后缀表示比较。

### 5. 注意：不是所有形容词都直接加 -er、-est

例如：

- beautiful → more beautiful → most beautiful
- good → better → best

这些属于后续扩展知识。

### 6. 家庭练习

**词形转换**

- tall → taller → tallest
- fast → faster → fastest
- small → smaller → smallest

**句子**

- My bag is bigger.
- This tree is the tallest.
- The red car is faster.

其中 bigger 涉及 Lesson 108 的双写规则，可作为预习例子。

### 7. 家长常见错误

- 将 -er 一律理解为“做某事的人”。
- 认为所有形容词都可以直接添加 -er、-est。
- 忽略比较级和最高级的意义区别。

## Lesson 101 — Suffix -ly

### 1. 学习目标

学习 -ly 的常见构词功能。

### 2. 示例单词

| 基础词 | 添加 -ly | 中文 |
|---|---|---|
| quick | quickly | 快速地 |
| slow | slowly | 缓慢地 |
| soft | softly | 轻柔地 |
| loud | loudly | 大声地 |
| kind | kindly | 友善地 |
| quiet | quietly | 安静地 |
| careful | carefully | 小心地 |

### 3. -ly 有什么作用？

- quick：快的。
- quickly：快速地。

例如：

- The rabbit is quick.
- The rabbit runs quickly.

quick 描述兔子的性质，quickly 描述动作进行的方式。

### 4. 与中文比较

中文：

- 快
- 快速地

英语：

- quick
- quickly

两者在表达方式上有一定相似性。

但英语并非所有副词都以 -ly 结尾，例如 fast 既可以作形容词，也可以作副词。

### 5. 家庭练习

**词形转换**

- slow → slowly
- quick → quickly
- loud → loudly

**句子**

- Walk slowly.
- Speak softly.
- The boy runs quickly.

### 6. 家长常见错误

- 认为所有 -ly 单词都是副词，例如 friendly 通常是形容词。
- 认为所有副词都必须以 -ly 结尾。
- 把 quickly 拆成两个没有意义联系的部分。

---

## Lesson 102 — Suffixes -less、-ful

### 1. 学习目标

学习两个常见后缀：

- -less：缺少、没有。
- -ful：具有、充满某种性质。

### 2. 示例单词

| 基础词 | -ful | -less |
|---|---|---|
| care | careful | careless |
| hope | hopeful | hopeless |
| help | helpful | helpless |
| use | useful | useless |
| fear | fearful | fearless |
| harm | harmful | harmless |

### 3. 意义解释

例如：

**careful**

小心的、谨慎的。

**careless**

粗心的。

再例如：

**helpful**

有帮助的。

**helpless**

无助的。

### 4. 与中文比较

可以借助中文的“有……的”“没有……的”理解。

例如：

- helpful：有帮助的。
- helpless：无助的。

但并不是所有 -ful、-less 单词都可以机械翻译。

### 5. 特别注意拼写

后缀 `-ful` 只有一个 l。

例如：

`help + ful → helpful`

不是 helpfull。

### 6. 家庭练习

**词义对比**

- careful / careless
- hopeful / hopeless
- helpful / helpless

**听写**

- helpful
- careful
- careless
- hopeful
- useless

**句子**

- My friend is helpful.
- Be careful.
- The broken toy is useless.

### 7. 家长常见错误

- 将 -ful 写成 -full。
- 认为 -less 与 -ful 总是严格相反。
- 只记住中文意思，不理解基础词和后缀的关系。

## Lesson 103 — Prefix un-

### 1. 学习目标

学习 un- 表示否定或相反动作的常见情况。

### 2. 示例单词

| 基础词 | 添加 un- | 中文 |
|---|---|---|
| happy | unhappy | 不快乐的 |
| kind | unkind | 不友善的 |
| fair | unfair | 不公平的 |
| safe | unsafe | 不安全的 |
| lucky | unlucky | 不幸运的 |
| lock | unlock | 解锁 |
| pack | unpack | 打开包裹；取出物品 |
| tie | untie | 解开 |

### 3. un- 的两种常见作用

**否定：**

- happy → unhappy
- fair → unfair

**反向动作：**

- lock → unlock
- tie → untie

### 4. 与中文比较

中文常用“不”“非”“解”等表达类似意义。

例如：

- 快乐 → 不快乐
- 公平 → 不公平
- 锁上 → 解锁

但英语 un- 的具体意义仍需要结合基础词判断。

### 5. 家庭练习

**词形转换**

- happy → unhappy
- fair → unfair
- lock → unlock
- tie → untie

**句子**

- The boy is unhappy.
- This game is unfair.
- Please unlock the door.

### 6. 家长常见错误

- 认为所有单词都能直接添加 un-。
- 认为 un- 只能表示“不”。
- 忽略 un- 与基础词之间的意义联系。

## Lesson 104 — Prefixes pre-、re-

### 1. 学习目标

学习：

- pre-：之前、预先。
- re-：再次、重新。

### 2. pre- 示例

| 单词 | 结构 | 中文 |
|---|---|---|
| preview | pre + view | 预览 |
| preheat | pre + heat | 预热 |
| preschool | pre + school | 学前教育 |
| prepay | pre + pay | 预付 |
| pretest | pre + test | 预先测试 |

### 3. re- 示例

| 单词 | 结构 | 中文 |
|---|---|---|
| reread | re + read | 重新阅读 |
| rewrite | re + write | 重写 |
| replay | re + play | 重放 |
| redo | re + do | 重做 |
| rebuild | re + build | 重建 |
| repaint | re + paint | 重新粉刷 |

### 4. 与中文比较

- pre-：类似“预先”“事先”。
- re-：类似“重新”“再次”。

例如：

`read → reread`

阅读 → 重新阅读。

### 5. 家庭练习

**词形转换**

- read → reread
- write → rewrite
- heat → preheat
- view → preview

**句子**

- Please reread the story.
- We need to preheat the oven.
- I will rewrite my sentence.

### 6. 家长常见错误

- 认为所有 re 开头的单词都有“再次”的意思，例如 red、real 并不能按 re- 前缀分析。
- 认为 pre- 可以添加到任意单词前。
- 忽略词缀与基础词的意义联系。

## Lesson 105 — Prefix dis-

### 1. 学习目标

学习 dis- 表示否定、相反或分离的常见情况。

### 2. 示例单词

| 基础词 | 添加 dis- | 中文 |
|---|---|---|
| agree | disagree | 不同意 |
| like | dislike | 不喜欢 |
| obey | disobey | 不服从 |
| appear | disappear | 消失 |
| connect | disconnect | 断开连接 |
| honest | dishonest | 不诚实的 |
| respect | disrespect | 不尊重 |

### 3. 与 un- 的区别

un- 和 dis- 都可能表示否定，但不能随意替换。

例如：

- unhappy：正确。
- disagree：正确。

不能简单地把它们替换成不符合常见英语用法的形式。

### 4. 与中文比较

dis- 可以与中文的“不”“非”“反”“断开”等意义联系起来。

但不同单词的实际意义需要结合语境理解。

### 5. 家庭练习

**词形转换**

- agree → disagree
- like → dislike
- appear → disappear

**句子**

- I disagree.
- I dislike loud noise.
- The rabbit disappeared.

### 6. 家长常见错误

- 认为 dis- 永远表示“不”。
- 将所有 dis 开头的单词都拆成前缀和基础词。
- 将 dis- 与 un- 随意替换。

# Part 5. Suffix Spelling Changes（后缀拼写变化）

## 5.1 为什么添加后缀时需要改变拼写？

英语单词添加后缀时，有时可以直接添加：

`jump + ing → jumping`

但有时需要改变基础词的拼写：

`run + ing → running`

`make + ing → making`

`happy + er → happier`

这些变化通常与英语的拼写规律有关。

### 与中文比较

中文构词时通常不会改变原有汉字的书写形式。

例如：

- 快
- 快乐
- 不快乐

但英语为了维持常见的拼写与发音关系，添加后缀时可能需要双写、删除或替换字母。

---

## Lesson 107 — Doubling Rule: -ed、-ing

### 1. 学习目标

学习添加 -ed、-ing 时的常见辅音双写规则。

### 2. 核心规律

对于许多以**单个短元音字母＋单个辅音字母**结尾的重读单音节基础词，添加以元音字母开头的后缀时，需要双写末尾辅音。

例如：

`run + ing → running`

`stop + ed → stopped`

### 3. 示例单词

| 基础词 | -ed | -ing |
|---|---|---|
| stop | stopped | stopping |
| plan | planned | planning |
| hop | hopped | hopping |
| rub | rubbed | rubbing |
| clap | clapped | clapping |
| slip | slipped | slipping |

### 4. 为什么需要双写？

比较：

- hop → hopping
- hope → hoping

两个单词的元音不同：

- hopping：短 o /ɑ/。
- hoping：长 o /oʊ/。

双写 p 有助于保持 hopping 中的短元音拼写模式。

### 5. 家庭练习

**分类**

将以下单词分成直接加后缀与需要双写两组：

jumping, running, helping, stopping, playing, hopping

**听写**

- running
- stopped
- planning
- hopping
- clapping

### 6. 家长常见错误

- 认为所有 CVC 单词都必须双写。
- 认为只要添加 -ing 就一定双写。
- 忽略单词重音和末尾字母的限制。

例如：

- rain → raining，不双写。
- help → helping，不双写。
- fix → fixing，不双写 x。

---

## Lesson 108 — Doubling Rule: -er、-est

### 1. 学习目标

学习添加 -er、-est 时的辅音双写规律。

### 2. 示例单词

| 原级 | 比较级 | 最高级 |
|---|---|---|
| big | bigger | biggest |
| hot | hotter | hottest |
| sad | sadder | saddest |
| thin | thinner | thinnest |
| wet | wetter | wettest |
| flat | flatter | flattest |

### 3. 为什么 big 要双写 g？

因为 big 是以单个短元音字母加单个辅音字母结尾的重读单音节词。

添加 -er 时：

`big + er → bigger`

### 4. 与中文比较

中文：

- 大
- 更大
- 最大

英语：

- big
- bigger
- biggest

除了添加后缀，英语还需要遵循拼写变化规则。

### 5. 家庭练习

**词形转换**

- big → bigger → biggest
- hot → hotter → hottest
- thin → thinner → thinnest

**听写**

- bigger
- biggest
- hotter
- thinner
- saddest

### 6. 家长常见错误

- 写成 biger。
- 写成 hotest。
- 认为所有形容词都必须双写末尾辅音。

例如 tall → taller，不需要双写，因为基础词已经以两个 l 结尾。

## Lesson 109 — Drop-e Rule

### 1. 学习目标

学习添加某些以元音字母开头的后缀时，去掉基础词末尾不发音的 e。

### 2. 示例单词

| 基础词 | 添加后缀 | 新单词 |
|---|---|---|
| make | -ing | making |
| ride | -ing | riding |
| hope | -ing | hoping |
| bake | -ed | baked |
| smile | -ing | smiling |
| nice | -er | nicer |
| large | -est | largest |

### 3. 为什么 make → making？

因为 make 以不发音的 e 结尾。

添加 -ing 时，通常先删除 e：

`make → mak + ing → making`

### 4. 与 Doubling Rule 对比

| 基础词 | 新单词 | 规则 |
|---|---|---|
| hop | hopping | 双写 p |
| hope | hoping | 去掉 e |
| sit | sitting | 双写 t |
| ride | riding | 去掉 e |
| plan | planning | 双写 n |
| make | making | 去掉 e |

### 5. 家庭练习

**Word Work**

- make → making
- hope → hoping
- ride → riding
- smile → smiling

**听写**

- making
- riding
- hoping
- baked
- smiling

### 6. 家长常见错误

- 写成 makeing。
- 写成 hopeing。
- 认为所有以 e 结尾的词添加任何后缀都必须去掉 e。

例如：

- hope + ful → hopeful
- care + less → careless

这里通常保留 e。

## Lesson 110 — y-to-i Rule

### 1. 学习目标

学习添加某些后缀时，将词尾 y 改为 i 的常见规律。

### 2. 核心规律

当基础词以**辅音字母＋y**结尾时，添加某些后缀通常需要将 y 改为 i。

例如：

`happy + er → happier`

`baby + es → babies`

### 3. 示例单词

| 基础词 | 新单词 | 变化 |
|---|---|---|
| happy | happier | y → i |
| happy | happiest | y → i |
| baby | babies | y → i |
| cry | cried | y → i |
| try | tried | y → i |
| easy | easier | y → i |
| funny | funniest | y → i |

### 4. 为什么 play 不改成 plaies？

因为 play 中 y 前面是元音字母 a。

因此：

- play → played
- play → plays

通常直接添加后缀。

比较：

| 基础词 | 词尾结构 | 新单词 |
|---|---|---|
| baby | 辅音＋y | babies |
| cry | 辅音＋y | cried |
| play | 元音＋y | played |
| enjoy | 元音＋y | enjoyed |

### 5. 特别注意 -ing

即使基础词以辅音＋y 结尾，添加 -ing 时通常也保留 y。

例如：

- cry → crying
- try → trying
- study → studying

不能写成 criing 或 triing。

### 6. 家庭练习

**词形转换**

- happy → happier
- baby → babies
- cry → cried
- try → trying
- play → played

**听写**

- happier
- babies
- cried
- tried
- crying

### 7. 家长常见错误

- 认为所有 y 都必须改为 i。
- 忽略 y 前面的字母是元音还是辅音。
- 将 crying 写成 criing。
- 将 played 写成 plaied。

## 6.1 核心规则表

# Part 8. 阅读与写作练习

## 8.1 阅读短文：The Helpful Friend

**The Helpful Friend**

Tom was unhappy.

He lost his favorite toy.

His friend Ben wanted to help.

Ben looked under the table.

He found the toy.

Tom was happier.

He thanked Ben for being helpful.

> 本文用于家庭阅读理解练习，并非严格限定 Lessons 1–110 已学规则的官方 Decodable Text。

### 阅读理解问题

1. Why was Tom unhappy?
2. Who helped Tom?
3. Where did Ben look?
4. How did Tom feel at the end?
5. Why do you think Ben was a helpful friend?
6. Can you retell the story in your own words?

这些问题分别练习事实理解、因果关系、人物情绪和故事复述。

- unhappy
- helpful
- running
- making
- happier

1. My friend is ______.

### Level 3：自主造句

从简单句开始：

`My friend is helpful.`

`My friend is very helpful because she helps me with my homework.`

# Part 9. 中国家长常见问题

### Q1：为什么 running 要双写 n？

因为 run 是以单个短元音字母＋单个辅音字母结尾的重读单音节词，添加 -ing 时通常需要双写末尾辅音。

### Q2：为什么 making 要去掉 e？

因为 make 以不发音的 e 结尾，添加 -ing 时通常去掉 e。

### Q3：为什么 happier 要把 y 改成 i？

因为 happy 以辅音字母＋y 结尾，添加 -er 时通常将 y 改为 i。

### Q4：为什么 crying 不改成 criing？

因为添加 -ing 时通常保留词尾 y。

### Q5：为什么 helpful 只有一个 l？

因为后缀 -ful 本身只包含一个 l。

### Q6：为什么 un- 和 dis- 都可以表示否定？

因为英语有不同来源和使用范围的否定前缀。

它们不能随意替换，需要结合具体单词学习。

### Q7：孩子需要背诵所有规则吗？

不建议只机械背诵。

更有效的方法是：

1. 识别基础词。
2. 理解词缀意义。
3. 观察词尾结构。
4. 应用拼写变化。
5. 阅读并理解完整单词。

# Part 12. 本单元总结

## 三个最重要的学习成果

**1. 理解单词可以由基础词和词缀组成。**

例如：

- unhappy = un- + happy
- helpful = help + -ful
- reread = re- + read

**2. 理解添加后缀可能需要改变拼写。**

例如：

- run → running
- make → making
- happy → happier

**3. 能通过词素结构帮助理解陌生单词。**

例如：

- careless
- unhelpful
- rewrite
- disagree

这意味着孩子开始将自然拼读（Phonics）与词素意识（Morphological Awareness）结合起来。
